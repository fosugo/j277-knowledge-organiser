Loops
📚 Key Vocabulary
while loop
Repeats code as long as a condition is True
for loop
Repeats code a fixed number of times. Use when you know exactly how many repetitions are needed.
range(start, stop)
Generates a sequence of numbers from start up to (but not including) stop
💡 Big Ideas
🐍 while loop vs for loop — side by side
# WHILE loop — repeat until condition is False
number = 1
while number <= 5:
    print(number)
    number = number + 1
# Output: 1  2  3  4  5

# FOR loop — repeat a fixed number of times
for i in range(1, 6):
    print(i * 7)
# Output: 7  14  21  28  35
📺 while loop counts 1 to 5; for loop prints the 7 times table up to 5×7=35
  • Use a while loop when you don't know how many repetitions needed — e.g
  • Use a for loop when you know the exact number of repetitions — e.g. repeat something exactly 10 times.
  • range(1, 10) gives: 1, 2, 3, 4, 5, 6, 7, 8, 9. It does NOT include the final number
✅ Knowledge Check
Q1 Which loop type should you use when you do NOT know how many repetitions are needed?
while loop — it keeps repeating as long as a condition is True, so it works when you cannot predict how many times in advance.
Q2 What numbers does range(1, 5) generate?
1, 2, 3, 4 — range() goes from the first number up to but NOT including the last number.
Q3 How many times does this loop run: for i in range(3):
3 times — range(3) generates 0, 1, 2 (three values), so the loop runs once for each value.

Lists
📚 Key Vocabulary
List
A variable that stores multiple values under one name
Element
A single item stored inside a list. The list scores = [125, 63, 35, 12] has four elements.
Index
The position number of an element in a list. Lists start at index 0, not 1
💡 Big Ideas
🐍 Creating, reading and updating a list
# Create a list of high scores
highscore = [125, 63, 35, 12]

# Read individual elements (index starts at 0)
print(highscore[0])    # Output: 125
print(highscore[1])    # Output: 63

# Update one element
highscore[1] = 200
print(highscore)       # Output: [125, 200, 35, 12]

# Add a new element to the end
highscore.append(52)
print(highscore)       # Output: [125, 200, 35, 12, 52]

# Use a for loop to add 10 to every score
for i in range(0, len(highscore)):
    highscore[i] = highscore[i] + 10
📺 Shows how to access index 0 and 1, update an element, append a new one, and loop through updating all elements
  • Without lists, storing 10,000 player scores would need 10,000 separate variables and 10,000 lines of code
  • List indexing starts at 0: scores[0] is the first item, scores[1] is the second. scores[-1] is always the last item.
  • To update an element: scores[1] = 126 changes the second element from its old value to 126.
✅ Knowledge Check
Q1 A list is: names = ["Ali", "Beth", "Carl"]. What does names[1] return?
Beth — lists are indexed from 0, so names[0] = "Ali", names[1] = "Beth", names[2] = "Carl".
Q2 What is the advantage of using a list instead of separate variables for 10,000 scores?
A list stores all 10,000 values under one name with one line of code. Separate variables would require 10,000 lines of code and 10,000 variable names.
Q3 You have: scores = [10, 20, 30]. Write the code to add the value 40 to the end of the list.
scores.append(40) — this adds 40 as a new element at the end. The list becomes [10, 20, 30, 40].

Procedures
📚 Key Vocabulary
Procedure
A named block of code defined with def. Call it by name to run all the code inside it
def
The Python keyword used to define (create) a procedure or function. Short for 'definition'.
Call
Running a procedure by using its name followed by brackets
💡 Big Ideas
🐍 A procedure with a parameter
# Define a procedure with one parameter
def printDouble(amount):
    print("Double", amount, "is", amount * 2)

# Call it three times with different values
printDouble(10)     # Output: Double 10 is 20
printDouble(50)     # Output: Double 50 is 100
printDouble(1862)   # Output: Double 1862 is 3724

# Without a procedure, this would need 3 separate lines
# With a procedure, changing the calculation only needs 1 edit
📺 Calls the same procedure three times with different values — the procedure handles all the work
  • If the same block of code appears three times in a program, put it in a procedure
  • Define a procedure: def myProcedure(): — then indent all the code inside
  • Parameters allow the same procedure to work with different values: def printDouble(amount): print(amount * 2)
✅ Knowledge Check
Q1 What Python keyword is used to define a procedure?
def — short for 'definition'. Example: def myProcedure(): defines a procedure called myProcedure.
Q2 Give ONE advantage of using procedures instead of repeating the same code.
Any of: if there is a bug, fix it in one place (not in every copy). Code is shorter and easier to read. Easier to update — change the procedure once and it updates everywhere.
Q3 Write the code to define a procedure called sayHello that prints 'Hello World'.
def sayHello(): print("Hello World") Then call it with: sayHello()

Functions
📚 Key Vocabulary
Function
Like a procedure, but it calculates and RETURNS a value
return
The Python keyword that sends a value back from a function to wherever it was called
Return value
The value sent back by a function using return
💡 Big Ideas
🐍 Procedure vs Function — the key difference
# PROCEDURE — performs an action, returns nothing
def showDouble(num):
    print("Double is:", num * 2)

showDouble(5)     # Output: Double is: 10
# You cannot store the result — it just prints

# FUNCTION — calculates and RETURNS a value
def calcDouble(num):
    return num * 2

result = calcDouble(5)   # result now stores 10
print(result)            # Output: 10
print(calcDouble(7))     # Output: 14
print(calcDouble(calcDouble(3)))  # Output: 12
📺 Shows how a procedure just prints while a function returns a useable value
  • Key difference: a procedure does something (prints, draws)
  • Without return, a function is just a procedure. The return keyword sends the calculated value back to wherever the funct
  • Example: def calcDouble(num): return num * 2. Then result = calcDouble(5) stores 10 in result
✅ Knowledge Check
Q1 What is the key difference between a procedure and a function?
A function returns a value using the return keyword so it can be stored or used further. A procedure performs actions but does not return a value.
Q2 What does the return keyword do?
It sends a calculated value back from the function to wherever it was called — so the result can be stored in a variable or used in another calculation.
Q3 def calcHalf(num): return num / 2. What does calcHalf(20) return?
10.0 — the function returns 20 divided by 2 = 10 (as a float because division in Python always returns a decimal).

Image Recognition
📚 Key Vocabulary
Pixel
A single tiny square of colour that makes up a digital image
Binary image
A black and white image where each pixel is stored as a single bit: 1 = white, 0 = black.
Bit depth
The number of bits used to store each pixel. More bits = more possible colours
💡 Big Ideas
  • Images are stored as a grid of pixels. Each pixel is a binary number. For black and white: 1 = white, 0 = black
  • Bit depth and colours: 1 bit = 2 colours, 2 bits = 4 colours, 3 bits = 8 colours, 8 bits = 256 colours
  • Pattern matching: compare each pixel of a test image against a stored pattern
✅ Knowledge Check
Q1 What is a pixel?
A single tiny square of colour that makes up a digital image. Images are built from a grid of millions of pixels.
Q2 In a binary (black and white) image, what does 0 represent?
Black — in a binary image, 0 = black and 1 = white.
Q3 How many colours can 3 bits per pixel represent?
8 — because 2³ = 2 × 2 × 2 = 8 different combinations.

Vector Graphics

Vector graphic
An image made from mathematical descriptions of shapes — lines, curves, circles and polygons
Object
A single shape or item in a vector image — e.g. a circle, rectangle or line
Fill
The colour inside a shape. A circle can have an orange fill and a blue stroke.
💡 Big Ideas

  • Vector graphics are used for: logos, cartoons, 3D wireframes, architectural plans, house plans, maps.

Vector images scale perfectly at any size — zoom to 400% and the image stays perfectly sharp because it is redrawn from maths each time.

Bitmap Graphics
📚 Key Vocabulary
Bitmap graphic
An image stored as a grid of individual pixels, each with a colour value stored in binary
Bit depth
The number of bits used to represent each pixel's colour
Colour map
A table mapping each binary number to a specific colour — the image stores binary numbers
💡 Big Ideas
  • Bitmap images store a colour value for every single pixel
  • Bit depth formula: number of colours = 2^(bits per pixel)
  • File size formula: file size (bits) = width (pixels) × height (pixels) × bit depth
✅ Knowledge Check
Q1 What is a bitmap image?
An image stored as a grid of individual pixels, each with a colour value stored in binary numbers.
Q2 How many colours can 4 bits per pixel represent?
16 — because 2⁴ = 2 × 2 × 2 × 2 = 16 different colour combinations.
Q3 A 10×10 pixel image uses 2 bits per pixel. How many bits of storage does it need?
10 × 10 = 100 pixels. 100 × 2 bits = 200 bits total.

Resolution & Layers
📚 Key Vocabulary
Resolution
The concentration of pixels in an image. For screens: measured in PPI (pixels per inch)
PPI (Pixels Per Inch)
Used for digital screens. 72 PPI is standard for most screens
DPI (Dots Per Inch)
Used for printed images. 300 DPI is recommended for high-quality print
💡 Big Ideas
  • Resolution controls quality: more pixels per inch = sharper image. 72 PPI is fine for screens
  • Reducing resolution: fewer pixels per inch = smaller file size BUT lower quality
  • Layers work like transparent plastic sheets stacked on top of each other
✅ Knowledge Check
Q1 What is the recommended resolution for images displayed on a screen?
72 PPI (pixels per inch) — this is adequate for clear display on most screens at normal viewing distance.
Q2 What is the recommended resolution for high-quality printed images?
300 DPI (dots per inch) — significantly higher than screen resolution to produce sharp, clear printed results.
Q3 What happens to a bitmap image's quality and file size if the resolution is reduced?
Quality decreases (becomes pixelated) AND file size decreases — fewer pixels means less data to store.

📚 Key Vocabulary
Magic Wand Tool
Selects all pixels of a similar colour in one click
Tolerance
A setting on the Magic Wand Tool — higher tolerance selects a wider range of similar colours
Magnetic Lasso Tool
Automatically snaps to the edges of an object as you trace around it
💡 Big Ideas

  • Magnetic Lasso: click to start, then trace carefully around the edges of your subject
  • After isolating: copy the subject onto a new background layer to create a composite
✅ Knowledge Check
Q1 When is the Magic Wand Tool most useful for isolating a subject?
When the background is a single consistent colour — e.g. a blue sky or white studio backdrop — so one click selects the entire background.
Q2 What does increasing the tolerance on the Magic Wand Tool do?
It selects a wider range of similar colours — useful if the background has slight colour variations and the standard setting is only capturing some pixels.
Q3 When would you use the Magnetic Lasso Tool instead of the Magic Wand?
When the background has many different colours — the Lasso snaps to the edges of the subject rather than selecting by colour.
