The Basics Revisited
📚 Key Vocabulary
Variable
A named location in memory storing one value. Example: guesses = 0 stores the number 0 in a variable called guesses.
Data Type
The kind of value stored in a variable. The main types are: string (text), integer (whole number) and float (decimal number).
Casting
Converting a value from one data type to another. Example: int("14") converts the string "14" into the integer 14.
Concatenation
Joining two strings together using +. Example: "Hello " + "World" gives Hello World. Numbers must be converted with str() first.
if / elif / else
Selection — runs different code depending on whether a condition is true or false. Always ends with a colon : and indented code below.
💡 Big Ideas
  • input() always returns a string. To do maths with it, convert it first: age = int(input("Enter age: "))
  • String + string concatenates (joins): "3" + "7" = "37". Integer + integer adds: 3 + 7 = 10. Never mix them without casting.
  • Casting: int() converts to integer, float() converts to decimal, str() converts to text. Use str() before joining numbers into printed sentences.
  • if / elif / else: use == to compare (not =). Always put a colon after the condition. Indent the code inside with 4 spaces.
  • Common mistakes: missing colon after if/elif/else, using = instead of == for comparison, wrong indentation, forgetting to cast input().
🐍 Password guesser — revisiting while, if and variables
correctPassword = "pa55word"
guesses = 0
guess = ""
while guess != correctPassword:
    guess = input("Try to guess the password: ")
    guesses = guesses + 1
if guesses == 1:
    print("Got it in 1 guess!")
else:
    print("Password guessed correctly.")
    print("That took you", guesses, "guesses.")

Q3 Write the code to ask for the user's age and store it as an integer.

Q4 Find TWO mistakes in this code: if score = 10 print("Ten!")
1. = should be == (use == for comparison, = for assignment). 2. Missing colon after the condition — should be: if score == 10:
Q5 What does str(42) do?
Converts the integer 42 into the string "42" — needed when joining a number into a sentence with concatenation.

Loops
📚 Key Vocabulary
while loop
Repeats code as long as a condition is True. Use when you do not know in advance how many times to repeat.
for loop
Repeats code a fixed number of times. Use when you know exactly how many repetitions are needed.
range(start, stop)
Generates a sequence of numbers from start up to (but not including) stop. Example: range(1, 5) gives 1, 2, 3, 4.
i
A variable name commonly used as a loop counter in for loops. It stores the current value from the range each time the loop runs.
Increment
Adding 1 to a variable each loop iteration: count = count + 1. Used to keep track of how many times something has happened.
💡 Big Ideas
  • Use a while loop when you don't know how many repetitions needed — e.g. keep asking for a password until the correct one is entered.
  • Use a for loop when you know the exact number of repetitions — e.g. repeat something exactly 10 times.
  • range(1, 10) gives: 1, 2, 3, 4, 5, 6, 7, 8, 9. It does NOT include the final number. range(1, 11) is needed to include 10.
  • for i in range(1, 5): runs the loop with i = 1, then i = 2, then i = 3, then i = 4. Four iterations total.
  • The doubling penny trick: 1p becomes 2p, then 4p, then 8p... After 30 weeks of doubling, it reaches over £5 million — loops make this easy to calculate.
🐍 while loop vs for loop — side by side
# WHILE loop — repeat until condition is False
number = 1
while number <= 5:
    print(number)
    number = number + 1
# Output: 1  2  3  4  5

# FOR loop — repeat a fixed number of times
for i in range(1, 6):
    print(i * 7)
# Output: 7  14  21  28  35
📺 Output: while loop counts 1 to 5; for loop prints the 7 times table up to 5×7=35
✅ Knowledge Check
Q1 Which loop type should you use when you do NOT know how many repetitions are needed?
while loop — it keeps repeating as long as a condition is True, so it works when you cannot predict how many times in advance.
Q2 What numbers does range(1, 5) generate?
1, 2, 3, 4 — range() goes from the first number up to but NOT including the last number.
Q3 How many times does this loop run: for i in range(3):
3 times — range(3) generates 0, 1, 2 (three values), so the loop runs once for each value.
Q4 A for loop repeats exactly 10 times, outputting i*2 each time. Write the code.
for i in range(1, 11): print(i * 2) This outputs 2, 4, 6, 8... up to 20.
Q5 What is the output of: for i in range(1, 5): print(i*7)?
7, 14, 21, 28 — i takes values 1, 2, 3, 4, and each is multiplied by 7.

Lists
📚 Key Vocabulary
List
A variable that stores multiple values under one name. Example: scores = [125, 63, 35, 12] stores four numbers.
Element
A single item stored inside a list. The list scores = [125, 63, 35, 12] has four elements.
Index
The position number of an element in a list. Lists start at index 0, not 1. scores[0] = 125, scores[1] = 63.
append()
Adds a new element to the end of a list. Example: scores.append(52) adds 52 as a new element at the end.
len()
Returns the number of elements in a list. Example: len(scores) returns 4 if scores has 4 elements.
💡 Big Ideas
  • Without lists, storing 10,000 player scores would need 10,000 separate variables and 10,000 lines of code. One list stores them all.
  • List indexing starts at 0: scores[0] is the first item, scores[1] is the second. scores[-1] is always the last item.
  • To update an element: scores[1] = 126 changes the second element from its old value to 126.
  • To add a new element to the end: scores.append(52). You cannot use scores[4] = 52 if index 4 doesn't exist yet.
  • Combine lists with for loops: for i in range(0, len(scores)): scores[i] = scores[i] + 1 adds 1 to every element — works for a list of any size.
🐍 Creating, reading and updating a list
# Create a list of high scores
highscore = [125, 63, 35, 12]

# Read individual elements (index starts at 0)
print(highscore[0])    # Output: 125
print(highscore[1])    # Output: 63

# Update one element
highscore[1] = 200
print(highscore)       # Output: [125, 200, 35, 12]

# Add a new element to the end
highscore.append(52)
print(highscore)       # Output: [125, 200, 35, 12, 52]

# Use a for loop to add 10 to every score
for i in range(0, len(highscore)):
    highscore[i] = highscore[i] + 10
📺 Output: Shows how to access index 0 and 1, update an element, append a new one, and loop through updating all elements
✅ Knowledge Check
Q1 A list is: names = ["Ali", "Beth", "Carl"]. What does names[1] return?
Beth — lists are indexed from 0, so names[0] = "Ali", names[1] = "Beth", names[2] = "Carl".
Q2 What is the advantage of using a list instead of separate variables for 10,000 scores?
A list stores all 10,000 values under one name with one line of code. Separate variables would require 10,000 lines of code and 10,000 variable names.
Q3 You have: scores = [10, 20, 30]. Write the code to add the value 40 to the end of the list.
scores.append(40) — this adds 40 as a new element at the end. The list becomes [10, 20, 30, 40].
Q4 Why can't you use scores[3] = 40 to add a new element to scores = [10, 20, 30]?
Because index 3 does not exist yet — the list only has indices 0, 1 and 2. You must use append() to create a new element.
Q5 Write a for loop that prints every element in a list called fruits.
for i in range(0, len(fruits)): print(fruits[i]) Or more simply: for fruit in fruits: print(fruit)

Procedures
📚 Key Vocabulary
Procedure
A named block of code defined with def. Call it by name to run all the code inside it. Example: def greetUser(): defines a procedure called greetUser.
def
The Python keyword used to define (create) a procedure or function. Short for 'definition'.
Call
Running a procedure by using its name followed by brackets. Example: greetUser() calls the greetUser procedure.
Parameter
Extra information passed into a procedure when calling it. Example: printDouble(10) passes 10 as a parameter called amount.
Modular code
Breaking a program into named procedures — each does one job. Makes code shorter, easier to read and easier to fix.
💡 Big Ideas
  • If the same block of code appears three times in a program, put it in a procedure. Write it once, call it as many times as needed.
  • Define a procedure: def myProcedure(): — then indent all the code inside. Call it anywhere in the program by writing myProcedure().
  • Parameters allow the same procedure to work with different values: def printDouble(amount): print(amount * 2). Then printDouble(5) prints 10, printDouble(20) prints 40.
  • Advantage: if there is a bug in a procedure, fix it in ONE place and it is fixed everywhere the procedure is called.
  • Advantage: modular code is easier for other programmers to read and understand — each procedure has a clear, descriptive name.
🐍 A procedure with a parameter
# Define a procedure with one parameter
def printDouble(amount):
    print("Double", amount, "is", amount * 2)

# Call it three times with different values
printDouble(10)     # Output: Double 10 is 20
printDouble(50)     # Output: Double 50 is 100
printDouble(1862)   # Output: Double 1862 is 3724

# Without a procedure, this would need 3 separate lines
# With a procedure, changing the calculation only needs 1 edit
📺 Output: Calls the same procedure three times with different values — the procedure handles all the work
✅ Knowledge Check
Q1 What Python keyword is used to define a procedure?
def — short for 'definition'. Example: def myProcedure(): defines a procedure called myProcedure.
Q2 Give ONE advantage of using procedures instead of repeating the same code.
Any of: if there is a bug, fix it in one place (not in every copy). Code is shorter and easier to read. Easier to update — change the procedure once and it updates everywhere.
Q3 Write the code to define a procedure called sayHello that prints 'Hello World'.
def sayHello(): print("Hello World") Then call it with: sayHello()
Q4 What is a parameter?
Extra information passed into a procedure when you call it — it lets the same procedure work with different values each time it is called.
Q5 def printLines(n): runs a loop n times printing dashes. Write the call to print 100 lines.
printLines(100) — this calls the procedure and passes 100 as the value of the parameter n.

Functions
📚 Key Vocabulary
Function
Like a procedure, but it calculates and RETURNS a value. The returned value can be stored in a variable or used directly.
return
The Python keyword that sends a value back from a function to wherever it was called. Example: return total sends the value of total back.
Return value
The value sent back by a function using return. Example: result = calcDouble(5) stores 10 in result (because calcDouble returns 5*2).
Procedure vs Function
A procedure performs actions but returns nothing. A function calculates a value and returns it so it can be used elsewhere.
Built-in function
Functions already available in Python without defining them: print(), input(), int(), len(), round() are all built-in functions.
💡 Big Ideas
  • Key difference: a procedure does something (prints, draws). A function calculates something and RETURNS the result for you to use.
  • Without return, a function is just a procedure. The return keyword sends the calculated value back to wherever the function was called.
  • Example: def calcDouble(num): return num * 2. Then result = calcDouble(5) stores 10 in result. Or print(calcDouble(7)) prints 14.
  • You can pass a function's return value straight into another function: print(calcDouble(calcDouble(3))) — inner calcDouble(3)=6, outer calcDouble(6)=12.
  • Python's built-in functions like len(), round() and int() all return values — you have been using functions all along!
🐍 Procedure vs Function — the key difference
# PROCEDURE — performs an action, returns nothing
def showDouble(num):
    print("Double is:", num * 2)

showDouble(5)     # Output: Double is: 10
# You cannot store the result — it just prints

# FUNCTION — calculates and RETURNS a value
def calcDouble(num):
    return num * 2

result = calcDouble(5)   # result now stores 10
print(result)            # Output: 10
print(calcDouble(7))     # Output: 14
print(calcDouble(calcDouble(3)))  # Output: 12
📺 Output: Shows how a procedure just prints while a function returns a useable value
✅ Knowledge Check
Q1 What is the key difference between a procedure and a function?
A function returns a value using the return keyword so it can be stored or used further. A procedure performs actions but does not return a value.
Q2 What does the return keyword do?
It sends a calculated value back from the function to wherever it was called — so the result can be stored in a variable or used in another calculation.
Q3 def calcHalf(num): return num / 2. What does calcHalf(20) return?
10.0 — the function returns 20 divided by 2 = 10 (as a float because division in Python always returns a decimal).
Q4 You call: answer = calcDouble(calcDouble(4)). What is stored in answer?
16 — calcDouble(4) returns 8, then calcDouble(8) returns 16. The inner function runs first.
Q5 Name THREE built-in Python functions you have already used.
Any three of: print(), input(), int(), float(), str(), len(), round(), range() — these are all built-in functions that return values.

What is AI?
📚 Key Vocabulary
Artificial Intelligence (AI)
An artificial creation with human-like intelligence — it can learn, solve problems and make decisions in ways that mimic how a human brain works.
Neural Network
A computer system inspired by neurons in the human brain. It classifies and makes decisions about information — like recognising a face or choosing which way to turn a car.
Classification
Sorting data into categories using rules. Example: an AI classifying whether a photo contains a cat or a dog.
Rules-based AI
An AI that follows a fixed set of hand-written rules. Example: if road ahead, go forward. If no road ahead and road left, turn left.
Training Data
The large set of examples used to teach an AI system. More training data generally produces better AI performance.
💡 Big Ideas
  • AI timeline: computerised draughts (1950s), ELIZA chatbot (1960s), ALVINN self-driving car (1980s), IBM Deep Blue beats chess champion (1990s), Roomba robot vacuum (2000s).
  • AI is used in: facial recognition on phones, speech recognition (Siri, Alexa), game AI opponents, medical diagnosis, spam email detection, self-driving cars.
  • At the heart of AI are neural networks — systems inspired by neurons in the human brain that classify information and make decisions.
  • Rules-based AI example (self-driving toy car): if road ahead → go forward. If no road ahead and road left → turn left. If obstacle hit → stop and turn around.
  • AI struggles with things humans find easy: understanding context, feeling emotions, comforting a friend, peeling an orange. These require more than pattern recognition.
✅ Knowledge Check
Q1 What is Artificial Intelligence?
An artificial creation with human-like intelligence — it can learn, solve problems and make decisions in ways that mimic how a human brain works.
Q2 Give THREE real-world uses of AI.
Any three of: facial recognition, fingerprint ID, speech recognition (Siri/Alexa), self-driving cars, game opponents, spam filters, medical scanning, robot vacuums.
Q3 In which decade did IBM Deep Blue beat a chess world champion?
1990s — IBM Deep Blue beat Garry Kasparov at chess in 1997.
Q4 What is a neural network?
A computer system inspired by neurons in the human brain — it classifies information and makes decisions, like recognising faces or deciding which way to steer a car.
Q5 Give ONE rule that a self-driving toy car's AI might follow.
Any reasonable rule, e.g. 'If road ahead → go forward' or 'If obstacle hit → stop and turn around'.

Machine Learning
📚 Key Vocabulary
Machine Learning (ML)
A type of AI where the machine works out the rules for itself from training data — rather than being given rules by a programmer.
Training Data
A large collection of examples given to a machine learning system so it can learn the rules automatically.
Structured Data
Data that has been organised into a clear format — e.g. a spreadsheet of monthly sales figures or hourly weather readings.
Unstructured Data
Data with no fixed format — e.g. emails, social media posts, newspaper articles, photos. ML is very powerful at finding patterns in this type of data.
Probability
How likely something is, expressed as a percentage or decimal. ML gives a probability for each classification — e.g. 95% match = almost certainly correct.
💡 Big Ideas
  • Traditional AI: a programmer writes the rules. Machine Learning: the machine writes its own rules by studying thousands of examples (training data).
  • ML for image classification: show the system thousands of labelled photos of birds. It creates its own rules — e.g. 'has wings', 'has beak' — then classifies new photos.
  • ML needs LOTS of training data to learn well. Too little data leads to poor rules — like judging all birds by only seeing three examples.
  • Applications of ML image classification: medical scan screening, quality control on production lines, self-driving car hazard detection, face recognition, spam email detection.
  • Strength: no need to manually write rules. Weakness: needs vast amounts of high-quality training data. Bad training data = bad rules.
✅ Knowledge Check
Q1 What is the key difference between rules-based AI and machine learning?
Rules-based AI follows rules written by a programmer. Machine learning works out its own rules automatically by studying large amounts of training data.
Q2 What is training data?
A large collection of examples given to a machine learning system so it can learn its own rules automatically.
Q3 Give TWO real-world applications of machine learning for image classification.
Any two of: medical scan screening, quality control on production lines, self-driving car hazard detection, face recognition, fingerprint ID, spam email detection.
Q4 Why does machine learning need large amounts of training data?
The more examples it sees, the better its rules become. Too little data leads to poor, inaccurate rules — like judging all birds from seeing only three examples.
Q5 What is the difference between structured and unstructured data?
Structured data is organised into a clear format (e.g. spreadsheet). Unstructured data has no fixed format (e.g. emails, social media posts, photos).

Ethics of AI
📚 Key Vocabulary
Ethics
The study of what is morally right or wrong. In AI, it covers questions like: should a self-driving car be programmed to harm fewer people in an unavoidable crash?
Utilitarianism
An ethical approach that aims to reduce overall harm — choosing the action that results in the least total suffering.
Automation
Using machines or AI to carry out tasks that were previously done by humans — often leading to job losses.
Bias in AI
When an AI produces unfair results because its training data was not representative — e.g. rejecting job applicants with non-European names.
Wealth inequality
The gap between people with more money and those with less. AI-driven automation could make companies richer while many workers lose their jobs.
💡 Big Ideas
  • Self-driving car dilemma: if brakes fail, should the car swerve to hit one person or stay straight and hit five? Moral rules must be programmed into the machine.
  • Up to 40% of jobs could be replaced by AI and automation by 2035 — telemarketing, taxi drivers, receptionists, retail sales and proof reading are all at risk.
  • Bias: if training data is not diverse, AI becomes biased. A job application AI trained only on European names may unfairly reject equally qualified candidates with non-European names.
  • AI could increase wealth inequality: companies profit from cheaper automated production, but workers lose jobs and income — requiring strong social support systems.
  • Ethical questions to ask about any AI: Is it reliable? Could it make mistakes? Is it secure? Could it be hacked? Is it fair to all groups?
✅ Knowledge Check
Q1 What is ethics in the context of AI?
Considering what is morally right or wrong when designing and using AI — e.g. how a self-driving car should be programmed to respond to unavoidable accidents.
Q2 Give ONE example of a job that could be replaced by AI or automation by 2035.
Any of: telemarketing, taxi driver, receptionist, retail sales assistant, proof reader, delivery driver.
Q3 What is bias in AI and why is it a problem?
When training data is not representative, the AI learns biased rules that produce unfair results — e.g. rejecting job applicants with non-European names despite equal qualifications.
Q4 Explain the ethical dilemma self-driving cars face.
In an unavoidable crash, the car's AI must decide who to harm. Moral rules must be programmed — but who decides which lives are prioritised?
Q5 AI automation could make companies richer while workers become poorer — True or False?
True — companies save money on wages through automation, but the workers who lose their jobs may face financial hardship.

Image Recognition
📚 Key Vocabulary
Pixel
A single tiny square of colour that makes up a digital image. A typical photo contains millions of pixels.
Binary image
A black and white image where each pixel is stored as a single bit: 1 = white, 0 = black.
Bit depth
The number of bits used to store each pixel. More bits = more possible colours. 1 bit = 2 colours, 8 bits = 256 colours, 24 bits = 16 million colours.
Pattern matching
Comparing a test image against a stored pattern pixel by pixel to calculate a percentage match.
Fuzzy logic
When an AI cannot be certain, it gives a probability for each possible answer rather than one definite answer.
💡 Big Ideas
  • Images are stored as a grid of pixels. Each pixel is a binary number. For black and white: 1 = white, 0 = black. Colour images need more bits per pixel.
  • Bit depth and colours: 1 bit = 2 colours, 2 bits = 4 colours, 3 bits = 8 colours, 8 bits = 256 colours, 24 bits = 16 million colours. Formula: 2^(number of bits).
  • Pattern matching: compare each pixel of a test image against a stored pattern. 91 pixels total, 5 wrong = (91-5)/91 = 95% match — almost certainly the same shape.
  • Facial recognition problems: head angle changes all measurements, objects/masks obscure the face, makeup and wigs change appearance, lighting affects pixel values.
  • Fuzzy logic: when an AI is unsure, it gives probabilities — e.g. 70% chance it's a square, 20% rectangle, 10% other — rather than forcing one answer.
✅ Knowledge Check
Q1 What is a pixel?
A single tiny square of colour that makes up a digital image. Images are built from a grid of millions of pixels.
Q2 In a binary (black and white) image, what does 0 represent?
Black — in a binary image, 0 = black and 1 = white.
Q3 How many colours can 3 bits per pixel represent?
8 — because 2³ = 2 × 2 × 2 = 8 different combinations.
Q4 An image has 100 pixels. 8 pixels do not match the pattern. What is the match percentage?
(100 - 8) / 100 = 92/100 = 92% match.
Q5 Give TWO reasons why facial recognition can struggle to identify a face correctly.
Any two of: head not facing camera directly, mask or object covering the face, makeup or wig, different lighting conditions, disguise.

Turing Tests & Chatbots
📚 Key Vocabulary
Turing Test
A test created by Alan Turing in 1950. A human asks questions to both a human and a computer. If they cannot tell which is which, the computer has passed the test.
Chatbot
A computer program that can respond to messages or voice commands — attempting to simulate a human conversation.
Virtual Assistant
A more sophisticated chatbot using AI and ML to answer spoken queries — examples: Siri, Alexa, Google Assistant.
Correlation
A pattern where two things change together — e.g. cinema ticket prices and GCSE pass rates both rise over time. Correlation does NOT mean one causes the other.
CAPTCHA
A test that uses distorted text or image puzzles that humans can solve easily but computers cannot — proving the user is human.
💡 Big Ideas
  • The Turing Test (1950): if a human cannot tell whether they are talking to a computer or another human, the computer has passed the test. No computer has fully passed yet.
  • Computers are good at finding patterns but bad at understanding WHY. Example: GCSE passes and cinema prices both rise over time — but neither causes the other.
  • Simple chatbots use keyword matching — they spot words like 'primary' and 'goal' and respond accordingly, sometimes misunderstanding context completely.
  • CAPTCHA exploits pattern recognition limits: distorted letters are hard for computers to decode, but humans can interpret them — proving you are human.
  • Virtual assistants (Siri, Alexa) use ML to improve over time. They are increasingly sophisticated but still fail at nuanced, contextual conversation.
✅ Knowledge Check
Q1 Who created the Turing Test and in what year?
Alan Turing created it in 1950. He proposed that if a human cannot tell the difference between talking to a computer and a human, the computer can be considered intelligent.
Q2 Describe how the Turing Test works.
A human asks questions to both a human and a computer through a screen. If they cannot tell which is the computer and which is the human, the computer has passed the test.
Q3 A computer sees 'primary goal' in a message and responds about scoring a goal in primary school. What went wrong?
The computer pattern-matched individual words (primary, goal) without understanding the full context — it misread 'primary goal in life' as being about football.
Q4 What is a CAPTCHA and why does it work?
A test using distorted text or images that humans can interpret easily but computers cannot reliably decode — proving the user is human, not an automated bot.
Q5 Give ONE limitation of current virtual assistants compared to a human.
Any reasonable answer, e.g. they misunderstand context, cannot comfort someone emotionally, struggle with complex or ambiguous questions, cannot truly understand meaning.

Sentiment Analysis
📚 Key Vocabulary
Sentiment Analysis
Using AI to determine whether a piece of text is positive, negative or neutral — by analysing the words used and their emotional weight.
Weighting
Assigning a score to a word based on how strongly positive or negative it is. 'Amazing' might score +5, 'good' scores +1, 'terrible' scores -5.
Word list
A list of words with associated sentiment scores used by a sentiment analysis program — also called a lexicon.
Fake reviews
Reviews written to deceive — either unfairly positive (to boost a product) or unfairly negative (to harm a competitor). Amazon deleted 20,000 fake UK reviews in 2020.
Negation
When 'not', 'never' or 'hardly' reverses the sentiment: 'not very good' is negative even though 'good' is a positive word.
💡 Big Ideas
  • Sentiment analysis: a program checks each word in a review against a word list, adds up the scores, and gives an overall rating — positive, negative or neutral.
  • Weighting matters: 'amazing' (+5), 'good' (+1), 'terrible' (-5), 'avoid' (-4). The total score determines the star rating.
  • Problems with simple sentiment analysis: negation ('not very good' seems positive because 'good' is positive), context ('I had hoped to see...' sounds positive but signals disappointment).
  • ML can improve sentiment analysis by learning from thousands of reviews with known star ratings — identifying which phrases signal positivity or negativity.
  • Uses: film/product review analysis, social media monitoring, political opinion tracking, customer feedback analysis, detecting fake reviews.
✅ Knowledge Check
Q1 What is sentiment analysis?
Using AI to determine whether text is positive, negative or neutral — by analysing words and their emotional weight (score).
Q2 Why do review sites have problems with fake reviews?
Fake reviews are written to mislead — boosting a product unfairly or damaging a competitor. Amazon deleted 20,000 fake UK reviews in 2020, generated by just 7 reviewers.
Q3 A review contains: 'amazing' (+5), 'superb' (+4), 'incredible' (+3). What is the total sentiment score?
+12 — add all the weights: 5 + 4 + 3 = 12, indicating a strongly positive review.
Q4 Why might a program incorrectly rate 'not very good' as positive?
Because 'good' is a positive word in the word list — the program scores it as positive without understanding that 'not' reverses its meaning. This is the negation problem.
Q5 How could machine learning improve sentiment analysis?
By studying thousands of real reviews alongside their star ratings — ML learns which words and phrases indicate positive or negative sentiment, including context and negation.

L1
Vector Graphics
📚 Key Vocabulary
Vector graphic
An image made from mathematical descriptions of shapes — lines, curves, circles and polygons. Stored as coordinates and properties rather than pixels.
Object
A single shape or item in a vector image — e.g. a circle, rectangle or line. Each has its own fill, stroke and position.
Fill
The colour inside a shape. A circle can have an orange fill and a blue stroke.
Stroke
The outline line around a shape — it has both a colour and a width (thickness).
Merge Shapes
Combining two or more shapes into one. Types: Union (combine all), Intersect (keep overlap only), Subtract (cut one shape from another).
💡 Big Ideas
  • Vector images store mathematical descriptions of shapes — not pixels. A circle is stored as: centre position (5,5), radius 5, fill orange, stroke blue.
  • Key advantage: vector images scale perfectly at any size. Zoom to 400% and the image stays perfectly sharp — because it is redrawn from maths, not pixels.
  • Vector graphics are used for: logos, cartoons, 3D wireframes, architectural plans, house plans, maps.
  • Screen coordinates: (0,0) is the TOP-LEFT corner. x increases going RIGHT. y increases going DOWN — the opposite of maths graphs.
  • Merge types in PowerPoint/Illustrator: Union = combine all shapes into one. Intersect = keep only the overlapping area. Subtract = remove one shape from another.

✅ Knowledge Check
Q1 What is stored in a vector image file?
Mathematical descriptions of shapes — coordinates, sizes, fill colours and stroke properties — NOT a grid of pixels.
Q2 Give ONE advantage of vector images over bitmap images.
Vector images scale perfectly at any size — zoom to 400% and the image stays perfectly sharp because it is redrawn from maths each time.
Q3 In screen coordinates, where is the point (0, 0)?
Top left — screen coordinates start at (0,0) in the top left. x increases going right, y increases going DOWN (opposite to maths graphs).
Q4 What does 'stroke' mean in vector graphics?
The outline line around a shape — it has a colour and a width (thickness). Separate from the fill colour inside the shape.
Q5 What does the 'Subtract' merge type do?
Removes one shape from another — like using a cookie cutter. The overlapping area of the second shape is cut out of the first.

L2
Bitmap Graphics
📚 Key Vocabulary
Bitmap graphic
An image stored as a grid of individual pixels, each with a colour value stored in binary. Also called a raster image.
Bit depth
The number of bits used to represent each pixel's colour. 1 bit = 2 colours, 8 bits = 256 colours, 24 bits = 16,777,216 colours.
Colour map
A table mapping each binary number to a specific colour — the image stores binary numbers, the colour map translates them to the colours you see.
File size
Calculated as: number of pixels × bits per pixel. More pixels and higher bit depth = larger file size.
Pixelation
The blocky, low-quality appearance of a bitmap image when zoomed in — because each pixel becomes a visible square.
💡 Big Ideas
  • Bitmap images store a colour value for every single pixel. A 10×10 pixel image at 1 bit per pixel needs 100 bits of storage.
  • Bit depth formula: number of colours = 2^(bits per pixel). 1 bit = 2 colours, 2 bits = 4, 3 bits = 8, 8 bits = 256, 24 bits = 16 million.
  • File size formula: file size (bits) = width (pixels) × height (pixels) × bit depth. A 100×100 pixel image at 8 bits per pixel = 80,000 bits = 10,000 bytes = ~10 KB.
  • Vector vs bitmap: vector scales perfectly (redrawn from maths), bitmap pixelates (each pixel becomes a visible square). Bitmap files are usually much larger.
  • Common bitmap formats: JPG, PNG, GIF, BMP. Common vector formats: SVG, AI (Adobe Illustrator), EPS.

✅ Knowledge Check
Q1 What is a bitmap image?
An image stored as a grid of individual pixels, each with a colour value stored in binary numbers.
Q2 How many colours can 4 bits per pixel represent?
16 — because 2⁴ = 2 × 2 × 2 × 2 = 16 different colour combinations.
Q3 A 10×10 pixel image uses 2 bits per pixel. How many bits of storage does it need?
10 × 10 = 100 pixels. 100 × 2 bits = 200 bits total.
Q4 What happens to a bitmap image when you zoom in?
It becomes pixelated — each pixel becomes a visible square block, making the image look blocky and low quality.
Q5 Is a PNG file a vector or bitmap format?
Bitmap — PNG stores a grid of pixels. SVG is an example of a vector format.

Resolution & Layers
📚 Key Vocabulary
Resolution
The concentration of pixels in an image. For screens: measured in PPI (pixels per inch). For print: measured in DPI (dots per inch).
PPI (Pixels Per Inch)
Used for digital screens. 72 PPI is standard for most screens — enough for clear display at normal viewing distance.
DPI (Dots Per Inch)
Used for printed images. 300 DPI is recommended for high-quality print — much higher than screen resolution.
Layer
A transparent 'sheet' in graphics software. Multiple layers stack on top of each other to build up a composite image.
Composite image
An image built from combining multiple photos, graphics and text layers — e.g. a film poster or advertisement.
💡 Big Ideas
  • Resolution controls quality: more pixels per inch = sharper image. 72 PPI is fine for screens. 300 DPI is needed for sharp print.
  • Reducing resolution: fewer pixels per inch = smaller file size BUT lower quality. The image becomes pixelated at lower resolutions.
  • Layers work like transparent plastic sheets stacked on top of each other. Each layer can be shown, hidden, moved or edited independently.
  • Composite images combine multiple photos and graphics using layers — film posters, adverts and magazine covers are all composites.
  • Transform tools: Resize (drag corner handles), Rotate (drag outside corner handles), Distort (move each corner independently to add perspective).

✅ Knowledge Check
Q1 What is the recommended resolution for images displayed on a screen?
72 PPI (pixels per inch) — this is adequate for clear display on most screens at normal viewing distance.
Q2 What is the recommended resolution for high-quality printed images?
300 DPI (dots per inch) — significantly higher than screen resolution to produce sharp, clear printed results.
Q3 What happens to a bitmap image's quality and file size if the resolution is reduced?
Quality decreases (becomes pixelated) AND file size decreases — fewer pixels means less data to store.
Q4 What is a layer in graphics software?
A transparent sheet in graphics software. Multiple layers stack on top of each other to build up a composite image — each can be edited independently.
Q5 What is a composite image?
An image built by combining multiple photos, graphics and text on separate layers — examples include film posters, advertisements and magazine covers.

L4
Isolating Images
📚 Key Vocabulary
Magic Wand Tool
Selects all pixels of a similar colour in one click. Best used when the background is a single, consistent colour — e.g. a blue sky.
Tolerance
A setting on the Magic Wand Tool — higher tolerance selects a wider range of similar colours. Lower tolerance is more precise.
Magnetic Lasso Tool
Automatically snaps to the edges of an object as you trace around it. Best used when the background has many different colours.
Selection
The area currently chosen for editing — shown by a dotted animated border (often called 'marching ants').
Select Inverse
Switches the selection from what you selected to everything ELSE — useful when it is easier to select the background than the subject.
💡 Big Ideas
  • Magic Wand Tool: click on the background to select it. If the selection is too small, increase the tolerance. Then Select > Inverse to switch to selecting the subject instead.
  • Magnetic Lasso: click to start, then trace carefully around the edges of your subject. The tool snaps to colour boundaries automatically. Press DELETE to undo a wrong snap.
  • After isolating: copy the subject onto a new background layer to create a composite. The subject appears naturally on the new background.
  • Select > Inverse (or Ctrl+Shift+I) switches the selection — if you selected the background, inverting gives you the subject instead.
  • Building a composite: isolate each element separately, copy each onto its own layer, then resize, reposition and rotate each layer to create the final composition.
✅ Knowledge Check
Q1 When is the Magic Wand Tool most useful for isolating a subject?
When the background is a single consistent colour — e.g. a blue sky or white studio backdrop — so one click selects the entire background.
Q2 What does increasing the tolerance on the Magic Wand Tool do?
It selects a wider range of similar colours — useful if the background has slight colour variations and the standard setting is only capturing some pixels.
Q3 When would you use the Magnetic Lasso Tool instead of the Magic Wand?
When the background has many different colours — the Lasso snaps to the edges of the subject rather than selecting by colour.
Q4 What does Select > Inverse do?
It switches the selection from the currently selected area to everything NOT selected — useful when selecting the background is easier than selecting the subject.
Q5 You isolate a footballer and a football separately. Describe how you would create a composite showing multiple footballs flying around the player.
Copy the football onto multiple separate layers. Move, resize and rotate each layer to different positions. Stack all layers over the footballer layer to create the composition.

Adding Text & Layer Effects
📚 Key Vocabulary
Text layer
A separate layer containing editable text in Photoshop. Text properties (font, size, colour, leading) can be changed at any time.
Leading
The vertical spacing between lines of text — named after the strips of lead used in old printing presses. In digital design, also called line spacing.
Layer effect
A visual effect applied to a layer — examples: Drop Shadow (shadow beneath), Stroke (coloured outline around edges).
Template layer
A guide layer showing where different elements should be placed — hidden in the final version but visible during design.
Rotate 180°
Turns a layer completely upside down. Used when creating greetings cards — the inside top section must be upside down so it reads correctly when folded.
💡 Big Ideas
  • Text in Photoshop goes on its own editable text layer. Properties: font size (controls how large the text is), leading (line spacing), colour (fill of the text itself).
  • Greetings card layout: fold A4 paper twice. The front cover appears bottom-right on the unfolded sheet. The inside top section must be rotated 180° so it reads correctly after folding.
  • Layer effects add depth and style: Drop Shadow (creates a shadow beneath the layer), Stroke (adds a coloured outline around the layer edges).
  • Template layers act as guides — they show safe margins, fold lines and placement zones. Click the eye icon to show/hide any layer.
  • Show/hide layers: click the eye icon next to any layer to toggle its visibility. Hidden layers do not appear in the final image but remain editable.
✅ Knowledge Check
Q1 What is 'leading' in text formatting?
The vertical spacing between lines of text — named after lead strips used in old printing. In digital design it is also called line spacing.
Q2 What is a layer effect?
A visual effect applied to a layer — examples: Drop Shadow (adds a shadow beneath), Stroke (adds a coloured outline around the edges).
Q3 On an unfolded A4 greetings card, where does the front cover appear?
Bottom right — because when the paper is folded twice, the bottom-right quarter becomes the front cover.
Q4 Why must the inside top section of a greetings card be rotated 180°?
Because it will be upside down when the paper is unfolded — rotating it 180° means it reads the correct way up after the paper is folded.
Q5 How do you show or hide a layer in Photoshop?
Click the eye icon to the left of the layer in the Layers panel — click it to toggle the layer between visible and hidden.
