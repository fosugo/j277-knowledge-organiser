Basic Shapes
📚 Key Vocabulary
Python
A text-based programming language used for everything from simple scripts to complex applications.
Turtle
A Python module that controls a cursor (the turtle) to draw shapes and patterns on screen.
import turtle as t
The line that loads the turtle module — must be at the top of every turtle program.
💡 Big Ideas — What You Need to Know

  • To draw a square: forward 100, left 90 — repeat 4 times. Turn angle = 360 ÷ number of sides.

📺 Output: Draws a square with sides of 100 pixels

import turtle as t (or import turtle)
Q2 Which direction does the turtle face at the start of a new program?
Right (east) — the turtle always starts pointing right at position (0,0).
Q3 What is the turn angle for drawing a regular hexagon (6 sides)?
60° — exterior angle = 360 ÷ 6 = 60°.

L2
More Complex Shapes
📚 Key Vocabulary
Exterior Angle
The angle a turtle turns at each corner. Always = 360 ÷ number of sides for a regular polygon.
Regular Polygon
A shape with all sides equal and all angles equal, e.g. equilateral triangle, square, pentagon.
Pentagon
A 5-sided regular polygon — turtle turn angle = 360 ÷ 5 = 72°.
💡 Big Ideas — What You Need to Know
  • The exterior angle rule: turn angle = 360 ÷ number of sides. Works for ANY regular polygon.
  • Pentagon: 5 sides, turn 72°. Hexagon: 6 sides, turn 60°. Octagon: 8 sides, turn 45°.
  • A 5-pointed star: move forward, turn 144° — repeat 5 times. The turtle crosses over itself.

Exterior angle = 360 ÷ number of sides.
Q2 What turn angle does the turtle use to draw a regular pentagon?
72° — exterior angle = 360 ÷ 5 = 72°.
Q3 The sum of all exterior angles of any polygon is always 360° — True or False?

📚 Key Vocabulary
t.penup()
Lifts the pen — the turtle moves without drawing.
t.pendown()
Puts the pen down — the turtle starts drawing again.
t.goto(x, y)
Moves the turtle to an exact coordinate position on the screen.
💡 Big Ideas — What You Need to Know

  • Always use t.penup() BEFORE t.goto() and t.pendown() AFTER — otherwise it draws a line.

✅ Knowledge Check
Q1 Why should you use # comments in a complex Python program like the house project?
To label each section (e.g. # Draw the roof) so you and others can understand what each part does.
Q2 Which command correctly sets the fill colour to tan?
t.fillcolor('tan') — note: no 'u' in fillcolor (American English spelling in Python).
Q3 You can start filling a shape before calling t.begin_fill() — True or False?
False — t.begin_fill() must be called BEFORE you start drawing the shape.
