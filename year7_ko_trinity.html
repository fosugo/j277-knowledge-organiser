File Management
📚 Key Vocabulary
AUP (Acceptable Use Policy)
The rules for using school computers — you must follow these at all times.
File Explorer
Software for managing and finding your files and folders on a computer.
Pathname
The full address of a file, e.g. C:\Year7\Computing\work.docx
Backup
A copy of your files stored somewhere safe in case the originals are lost.
Shortcut Key
A keyboard combination that does something quickly, e.g. Ctrl+C to copy.
💡 Big Ideas — What You Need to Know
  • Your school has an AUP — rules for using computers. Breaking them can get you in serious trouble.
  • Files should be saved with clear, meaningful names — not 'Document1' or 'Stuff'.
  • Folders form a tree structure: one root folder → sub-folders → files inside.
  • Always back up your work — save copies to the cloud or another device.
  • Key shortcuts: Ctrl+C (copy), Ctrl+V (paste), Ctrl+Z (undo), Win+E (File Explorer), F2 (rename).
✅ Knowledge Check
Q1 What does AUP stand for?
Acceptable Use Policy
Q2 Which shortcut opens Windows File Explorer?
Win+E — hold the Windows key and press E.
Q3 A backup is a spare copy of your files — True or False?
True — a backup is a spare copy stored somewhere safe.
Q4 Give ONE way you can back up your files.
Copy to another device OR upload to cloud storage (e.g. OneDrive, Google Drive).
Q5 Improve this filename: 'Stuff.jpg'
Any meaningful name, e.g. 'Cat on sofa.jpg' or 'School trip photo.jpg'.

Social Media

Cyberbullying
Bullying that happens online using phones, apps or the internet.
CEOP

Privacy Settings
Controls that decide who can see your posts and profile online.
Online Profile

Child Exploitation and Online Protection.

False — it can be copied and shared, making it nearly impossible to remove.

Keeping Data Safe
📚 Key Vocabulary
Password
A secret combination of characters used to log into an account.
Brute-Force Attack
When a computer tries thousands of password combinations automatically to hack an account.
Captcha
A distorted image test that proves you're human, not a computer guessing passwords.
Identity Theft
When someone uses your personal information to pretend to be you.
Phishing
A fake email or message trying to trick you into giving personal information like a password.
💡 Big Ideas — What You Need to Know
  • A strong password: 10+ characters, uppercase & lowercase letters, numbers and special characters (#$£%).
  • Trick: combine 3 random words + numbers, e.g. duck#foX8prison — easy to picture, hard to guess!
  • Always change default passwords on new devices. Lock your computer with Win+L when you leave it.
  • Identity theft: criminals use your name, address & date of birth to open accounts pretending to be you.
  • Phishing emails look real but have signs: spelling mistakes, urgent threats, suspicious links.
✅ Knowledge Check
Q1 Which of these is the STRONGEST password?
duck#foX8prison — combines 3 random words, uppercase letters, numbers and special characters.
Q2 What shortcut locks a Windows computer?
Win+L — hold the Windows key and press L.
Q3 What is a phishing email trying to do?
Trick you into giving personal information such as your username and password.
Q4 A brute-force attack guesses passwords automatically — True or False?
True — a computer tries thousands of combinations automatically.
Q5 Name ONE alternative to passwords for logging in.
Any of: fingerprint scanner, facial recognition, PIN, RFID fob, or pattern.

Using Email
📚 Key Vocabulary
Email Client
An app (like Outlook or Gmail) used to send and read emails on your device.
Attachment
An extra file added to an email — a copy is sent, the original stays on your device.
CC (Carbon Copy)
Sends a copy to extra people — everyone can see who was CC'd.
BCC (Blind Carbon Copy)
Sends a copy to extra people — no one can see who was BCC'd.
Email Signature
Text automatically added to the end of your emails, e.g. your name and contact details.
💡 Big Ideas — What You Need to Know
  • Email travels through mail servers around the world before reaching the recipient's inbox.
  • Use formal language: polite greeting (Hi / Dear), professional tone, and a sign-off (Regards).
  • Attachments are copies of files — reduce large photos before sending (many servers limit 10MB).
  • TO = main recipient. CC = extra people who should see it. BCC = hidden extra recipients.
  • Search emails using keywords from the subject or body. Ctrl+H shows your email history.
✅ Knowledge Check
Q1 What does BCC stand for?
Blind Carbon Copy — the recipients are hidden from everyone else who receives the email.
Q2 Sending an attachment deletes the original file from your computer — True or False?
False — a copy is sent; the original file stays on your computer.
Q3 Which part of an email tells the reader what the message is about?
Subject — the subject line is a short summary of what the email is about.
Q4 What is an email signature?
Text automatically added to the end of every email, usually your name and contact details.
Q5 Why should you reduce large image file sizes before attaching them?
Email providers limit attachment sizes (often around 10MB) — files that are too large may fail to send.

Searching the Web
📚 Key Vocabulary
Search Engine
A tool (like Google or Bing) that searches websites and shows you results.
Web Spider
A small program that visits web pages and stores keywords in a database for searching.
Keyword
The important words you type into a search engine — not 'the', 'a', 'it' etc.
Bookmark
A saved link to a website so you can find it again quickly (shortcut: Ctrl+D).
URL
The web address of a page, e.g. www.bbc.co.uk — helps you check if a site is reliable.
💡 Big Ideas — What You Need to Know
  • Use only keywords in searches — not full sentences. 'hotel London pool' works better than a full question.
  • Search operators: use – to exclude words, "speech marks" for exact phrases, filetype:pdf for PDFs only.
  • Web spiders crawl websites and store keywords — your search matches those stored keywords.
  • Not all websites are reliable — check the URL (.gov.uk is trustworthy), the author and the date.
  • Bookmark useful sites with Ctrl+D. View your web history with Ctrl+H.
✅ Knowledge Check
Q1 Which shortcut bookmarks a webpage?
Ctrl+D — press Ctrl and D together to bookmark the current page.
Q2 What does the – operator do in a search, e.g. 'cat –lion'?
Excludes results containing that word — results about cats but NOT lions.
Q3 A .gov.uk website is generally more reliable than a random blog — True or False?
True — .gov.uk sites are official UK government websites and are generally more trustworthy.
Q4 What does searching with speech marks do?
Finds pages with that exact phrase — results must contain those words in that exact order.
Q5 Name ONE way to check if a website is reliable.
Any of: check the URL/domain, check who wrote it, check the date, look for a padlock.

L1
Flowcharts
📚 Key Vocabulary
Algorithm
A set of step-by-step instructions that solve a problem.
Flowchart
A visual diagram showing an algorithm using shapes and arrows.
Sequence
Steps that happen one after another, in order.
Flowol
Software for creating flowcharts that control real-world simulations (mimics).
Infinite Loop
A sequence that repeats forever — an arrow loops back to the start.
💡 Big Ideas — What You Need to Know
  • Flowcharts show the sequence of steps to solve a problem — they are a visual algorithm.
  • Each symbol has a specific meaning: oval=Start/Stop, rectangle=Process, parallelogram=Output, diamond=Decision.
  • An infinite loop uses an arrow that loops back so the sequence repeats forever.
  • Flowol programs mimics — simulations like zebra crossings and traffic lights.
  • Traffic light sequence: Red → Red+Amber → Green → Amber → Red, with delays between each stage.
✅ Knowledge Check
Q1 What is an algorithm?
A set of step-by-step instructions that solve a problem or complete a task.
Q2 Which flowchart symbol is used for a decision (Yes/No)?
Diamond — with Yes and No arrows coming out.
Q3 A sequence means steps happen one after another in order — True or False?
True — a sequence is steps occurring one after another in a fixed order.
Q4 What shape is used for Start and Stop in a flowchart?
An oval (or rounded rectangle).
Q5 What is an infinite loop in a flowchart?
When an arrow loops back to an earlier step so the sequence repeats forever without stopping.

L2
Decisions
📚 Key Vocabulary
Decision
A Yes/No question in a flowchart that sends the program down different paths.
Control System
A system that monitors inputs and controls outputs automatically.
Input
Information going INTO a system, e.g. a button press or sensor reading.
Output
The result of the system, e.g. a light turning on or a motor moving.
Mimic
A simulation in Flowol of a real-world system, e.g. a log flume.
💡 Big Ideas — What You Need to Know
  • Decisions use a diamond shape — two arrows come out, labelled Yes and No.
  • Without decisions, a flowchart just runs in sequence. Decisions let it react to inputs.
  • A control system constantly checks inputs (buttons, sensors) to decide what to do next.
  • Log flume mimic: button pressed → check if boat ready → open barrier → fountain controlled by sensors.
  • Real-world examples: rollercoasters, car doors, traffic lights and lifts all use control systems.
✅ Knowledge Check
Q1 What shape is used for a decision in a flowchart?
Diamond — with Yes and No arrows coming out of it.
Q2 How many arrows come out of a decision diamond?
2 — one labelled Yes and one labelled No.
Q3 An input is information going INTO a system — True or False?
True — inputs include buttons, sensors and switches.
Q4 Give ONE example of how decisions are used to control a car.
Any of: checking if wiper lever is moved, if a button starts the engine, if fuel is low to flash a warning.
Q5 What is a mimic in Flowol?
A simulation of a real-world control system that you can program in Flowol.

Sensors
📚 Key Vocabulary
Sensor

LDR (Light Dependent Resistor)
A sensor detecting light levels — used in automatic lighting.
PIR (Passive Infra-Red)
A motion detector sensor — detects movement from body heat.
Temperature Sensor
Detects how hot or cold the environment is — used in heating and greenhouses.
Smart Home
A home where devices are automatically controlled using sensors.
💡 Big Ideas — What You Need to Know
  • Sensors are input devices — they detect changes (light, heat, movement, moisture) and send a signal.
  • Smart homes use sensors to automatically control heating, lighting, blinds, sprinklers and alarms.
  • Automatic Home mimic: temperature, light and motion sensors trigger outputs automatically.
  • Greenhouse mimic: moisture, light and temperature sensors control watering, ventilation and heating.
  • Multiple sensors can work together — each watches a different part of the environment.
✅ Knowledge Check

Q3 An LDR sensor detects temperature — True or False?
False — an LDR detects light levels. A temperature sensor detects heat.
Q4 Name TWO things a smart home could automatically control.
Any two of: heating, lighting, blinds, air conditioning, sprinklers, garage doors, fire/burglar alarms.
Q5 Name ONE sensor in the greenhouse mimic and what it detects.
Any of: moisture sensor (water levels), LDR (sunlight), temperature sensor (heat).

Subroutines
📚 Key Vocabulary
Subroutine
A named mini-flowchart called from another flowchart — a shortcut for a set of steps.
Call
When a flowchart runs a subroutine — it jumps to it and then returns.
Abstraction
Hiding detail so you can think about what something does, not how.
Sub Symbol
The rounded rectangle shape used to start and to call a subroutine.
Modular Design
Breaking a program into smaller parts that each do one job.
💡 Big Ideas — What You Need to Know
  • Subroutines are named mini-flowcharts — call them from a main flowchart whenever needed.
  • The same subroutine can be called many times from different flowcharts — no repeating steps.
  • Subroutines support abstraction — say 'Stop Train' without worrying about exact steps until later.
  • In large projects, different developers can build and test different subroutines at the same time.
  • Train set mimic: subroutines control starting/stopping the train, lights, and level crossing barriers.
✅ Knowledge Check
Q1 What is a subroutine?
A named mini-flowchart that can be called from another flowchart to run a specific set of steps.
Q2 A subroutine can only be called once — True or False?
False — a subroutine can be called as many times as needed from as many flowcharts as you like.
Q3 Give ONE advantage of using subroutines.
Any of: avoids repeating code, makes programs easier to read, different developers can work on different parts.
Q4 What shape is used to start and call a subroutine?
Rounded Rectangle — the Sub symbol is used both to define and to call the subroutine.
Q5 In the train mimic, what does the In_Tunnel subroutine do?
Turns train lights on when entering the tunnel, watches for the exit sensor, then turns lights off.

Actuators & Variables
📚 Key Vocabulary
Actuator
A device using a motor to cause physical movement, e.g. opening a barrier or door.
Variable
A named storage location in memory holding a value that can change.
Initialise
Setting a variable to its starting value at the beginning of a program.
7-Segment Display
A digital number display made of 7 lights that can show digits 0–9.
Counter
A variable used to count something, e.g. the number of cars in a car park.
💡 Big Ideas — What You Need to Know
  • Actuators use motors to cause movement — barriers, valves, blinds and doors are all actuators.
  • A variable is like a labelled box in memory — it stores a value that changes as the program runs.
  • Car park mimic: variable 'Spaces' starts at 8, decreases by 1 when a car enters, increases by 1 when one leaves.
  • Variables are used as counters, to store sensor readings, and to drive decisions based on changing values.
  • 7-segment displays show digits 0–9 using 7 separate lights in different combinations.

Q2 What is a variable in a program?

Q3 In the car park mimic, what is the starting value of the Spaces variable?
8 — the car park has 8 spaces, so Spaces starts at 8 and counts down as cars enter.
Q4 A 7-segment display uses 7 lights to show different digits — True or False?
True — seven lights (segments) are turned on or off in different combinations to show digits 0–9.
Q5 Give ONE real-life example of an actuator.
Any of: automatic doors, car park barriers, vending machine mechanisms, digger hydraulics.

Movement in Scratch
📚 Key Vocabulary
Sprite
An object above the backdrop that can be moved and programmed.
Backdrop
The fixed background image — platforms, walls and scenery are drawn here.
Event
Something that triggers code: clicking the green flag or pressing a key.
Forever Loop
Repeats the blocks inside it continuously until the program stops.
If Statement
Checks a condition — runs the blocks inside only if the condition is true.
💡 Big Ideas — What You Need to Know
  • Scratch uses draggable coloured blocks — each block is one programming instruction.
  • Sprites move using degrees: 0°=up, 90°=right, 180°=down, -90°=left.
  • Events start code: green flag = program start; key press event = keyboard input.
  • Wrap movement code in a forever loop so it keeps checking for key presses.
  • Use if statements inside a forever loop to detect multiple keys pressed at the same time.
✅ Knowledge Check
Q1 What is a sprite in Scratch?
An object above the backdrop that can be moved and programmed.
Q2 Which direction (degrees) makes a sprite point upward?
0° — in Scratch: 0°=up, 90°=right, 180°=down, -90°=left.
Q3 A forever loop repeats the blocks inside continuously — True or False?
True — a forever loop keeps repeating until the program is stopped.
Q4 What does the 'if on edge, bounce' block do?
Makes the sprite reverse direction when it hits the edge of the screen.
Q5 Why is an if statement better than a key press event for multiple keys?
A key press event only detects one key at a time. An if statement can check multiple keys at once.

Broadcasting & Outputs
📚 Key Vocabulary
Broadcast
Sends a named message to all sprites — any with a matching 'when I receive' block reacts.
Concurrency
Running two or more sets of code at the same time — Scratch does this automatically.
Say Block
Outputs text in a speech bubble above the sprite for a set number of seconds.
Think Block
Outputs text in a thought bubble above the sprite.
When I receive [msg]
An event block that runs when a specific broadcast message is received.
💡 Big Ideas — What You Need to Know
  • Scratch runs multiple scripts simultaneously — this is concurrency.
  • The broadcast block sends a message to ALL sprites — matching 'when I receive' blocks react.
  • Broadcasts trigger events across sprites, e.g. fish broadcasts 'EndGame' → starfish says 'Game Over!'
  • Say = speech bubble; Think = thought bubble. Both can show text for a timed duration.
  • Concurrent code runs faster — two blocks running at the same time finish in half the time.
✅ Knowledge Check
Q1 What does the broadcast block do?
Sends a named message to ALL sprites — any with a matching 'when I receive' block runs its code.
Q2 What is concurrency?
Running two or more sets of code at the same time — Scratch does this automatically.
Q3 The say block shows a thought bubble — True or False?
False — the say block shows a SPEECH bubble. The think block shows a thought bubble.
Q4 Program B uses concurrency, Program A doesn't. Which finishes first?
Program B — concurrency means two parts run at the same time, finishing in half the time.
Q5 What event block does a sprite use to react to a broadcast?
'When I receive [message name]' — runs when the matching broadcast is sent.

Jumping & Enemies
📚 Key Vocabulary
Jump Speed (Vertical Velocity)
A variable storing how fast the sprite moves up or down — gravity reduces this each loop.
Gravity (simulated)
In Scratch: decrease Jump Speed by 1 every loop to pull the sprite back down.
Colour Detection
Checking if a sprite is touching a specific colour — used to detect landing on a platform.
Repeat Loop
Runs the blocks inside a fixed number of times, e.g. repeat 20 to move an enemy.
Lives Variable
Stores lives remaining — decreases by 1 when the player touches an enemy.
💡 Big Ideas — What You Need to Know
  • Jump: set Jump Speed to 12 when up-arrow pressed (on platform). Change y by Jump Speed each loop.
  • Subtract 1 from Jump Speed each loop to simulate gravity — sprite slows, stops, then falls.
  • Use colour detection to check if the player is touching the platform — only allow jumping when on a platform.
  • Enemies: use repeat loop (move forward N times, backward N times) inside a forever loop.
  • When player touches enemy: Lives -1. If Lives = 0 → stop all. Otherwise → go back to start.
✅ Knowledge Check
Q1 How is gravity simulated in Scratch?
By decreasing the Jump Speed variable by 1 every loop — slows upward movement and pulls the sprite back down.
Q2 What value is Jump Speed set to when the player presses jump?
12 — set to 12 to launch upward; gravity reduces this by 1 each loop.
Q3 You can only jump when touching the platform colour — True or False?
True — colour detection checks if the player is on a platform before allowing a jump.
Q4 How do you make an enemy move back and forth automatically?

L2
More Complex Shapes
📚 Key Vocabulary
Exterior Angle
The angle a turtle turns at each corner. Always = 360 ÷ number of sides for a regular polygon.
Regular Polygon
A shape with all sides equal and all angles equal, e.g. equilateral triangle, square, pentagon.
Pentagon
A 5-sided regular polygon — turtle turn angle = 360 ÷ 5 = 72°.
Hexagon
A 6-sided regular polygon — turtle turn angle = 360 ÷ 6 = 60°.
Star
Drawn by turning 144° at each point — the turtle crosses over itself to create the star.
💡 Big Ideas — What You Need to Know
  • The exterior angle rule: turn angle = 360 ÷ number of sides. Works for ANY regular polygon.
  • Pentagon: 5 sides, turn 72°. Hexagon: 6 sides, turn 60°. Octagon: 8 sides, turn 45°.
  • A 5-pointed star: move forward, turn 144° — repeat 5 times. The turtle crosses over itself.
  • Right-angled triangle: one angle is 90°, so the turns will not all be equal.
  • The sum of ALL exterior angles of ANY polygon is always 360°.

Exterior angle = 360 ÷ number of sides.

L3
Combining Shapes & Moving
📚 Key Vocabulary
t.penup()
Lifts the pen — the turtle moves without drawing.
t.pendown()
Puts the pen down — the turtle starts drawing again.
t.goto(x, y)
Moves the turtle to an exact coordinate position on the screen.
Coordinates (x, y)
x = left/right (negative = left). y = up/down (negative = down). Centre = (0, 0).
Comment (#)
A line starting with # that Python ignores — used to explain what the code does.
💡 Big Ideas — What You Need to Know
  • To draw inside a shape: t.penup() → t.goto(x, y) → t.pendown() before drawing again.
  • The coordinate system: (0,0) is the centre. x increases going right; y increases going up.
  • Always use t.penup() BEFORE t.goto() and t.pendown() AFTER — otherwise it draws a line.
  • Combining shapes: draw one shape, penup, goto new position, pendown, draw another shape.
  • Use # comments to label sections — e.g. # Draw the cat's head. Makes complex programs readable.

t.goto(150, 0)

(0, 0) — the turtle always starts at the centre of the screen.
Q3 t.goto() moves the turtle without drawing a line — True or False?

Q4 What symbol is used to write a comment in Python?
# (hash symbol) — Python ignores everything on a line after a #.
Q5 If a turtle is at (0,0) and you run t.goto(-100, 50), where does it move?

L4
Formatting & Colour
📚 Key Vocabulary
t.pencolor('red')
Sets the colour of the line the turtle draws. Must be set BEFORE drawing the line.
t.pensize(n)
Sets the thickness of the pen line in pixels.
t.fillcolor('blue')
Sets the colour that will be used to fill a shape.
t.begin_fill()
Tells the turtle to start filling in the shape — place BEFORE drawing the shape.
t.end_fill()
Tells the turtle to stop filling in — place AFTER the shape is complete.
💡 Big Ideas — What You Need to Know
  • Set t.pencolor() and t.pensize() BEFORE drawing — they affect lines drawn after the command.
  • To fill a shape: t.fillcolor('red') → t.begin_fill() → draw shape → t.end_fill()
  • Colours can be names ('red', 'blue') or hex codes ('#FF0000').
  • t.pensize() takes a number — e.g. t.pensize(3) NOT t.pensize('3').
  • Use t.penup() to move to the fill area, then t.pendown() to draw inner detail.

t.pencolor('blue')
t.pensize(3)
t.fillcolor('yellow')
t.begin_fill()
t.forward(100)
t.left(90)
t.forward(100)
t.left(90)
t.forward(100)
t.left(90)
t.forward(100)
t.left(90)
t.end_fill()
📺 Output: Draws a blue-outlined yellow square with a thick border
✅ Knowledge Check
Q1 Which of these correctly sets the pen colour to red?
t.pencolor('red') — this is the correct turtle command to set the line colour.
Q2 t.begin_fill() must be placed BEFORE drawing the shape — True or False?
True — t.begin_fill() tells Python to start tracking the shape for filling.
Q3 What command stops the turtle filling a shape?
t.end_fill() — this must be placed after the shape is complete.
Q4 Which command sets the thickness of the pen line?
t.pensize() — e.g. t.pensize(5) sets a thick line.
Q5 Why won't a shape fill with colour if t.end_fill() is missing?
Python never receives the signal to finish and apply the fill — begin_fill() is opened but never closed.
