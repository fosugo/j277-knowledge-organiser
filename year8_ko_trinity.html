Network Topologies
📚 Key Vocabulary
LAN (Local Area Network)
A network of computers connected within a small geographical area — for example, a school
WAN (Wide Area Network)
A network that connects two or more LANs across a large geographical area
Network Topology
The way devices in a network are connected and arranged. Common topologies include bus and star.
💡 Big Ideas
  • LAN = one building or site (school, office, home). WAN = joins LANs across large distances using leased lines
  • Bus network: all computers share ONE cable. Cheap and easy to install
  • Star network: each computer has its own cable to a central switch
✅ Knowledge Check
Q1 What is the difference between a LAN and a WAN?
A LAN connects devices in a small area (one building or site). A WAN connects two or more LANs across large distances, using leased lines — the Internet is the world's largest WAN.
Q2 In a bus network, what happens if the main cable is cut?
All computers on the network immediately lose their connection — because every device shares that single cable.
Q3 Which topology gives each device its own cable connected to a central switch?
Star network — each device has its own dedicated cable to the central switch, so a single cable failure only disconnects one device.

Searching Algorithms
📚 Key Vocabulary
Linear Search
A search algorithm that checks each item one at a time, starting from the first
Binary Search
A search algorithm that repeatedly divides a sorted list in half — checking the middle item
Algorithm Efficiency
How quickly an algorithm completes, especially for large datasets
💡 Big Ideas
🐍 Linear search vs Binary search — side by side
# LINEAR SEARCH — checks every item one by one
hiddenNumber = 19
currentNumber = 1
foundNumber = False
while not foundNumber and currentNumber <= 100:
    if currentNumber == hiddenNumber:
        print("Found:", currentNumber, "(linear search)")
        foundNumber = True
    else:
        currentNumber = currentNumber + 1
# This took 19 comparisons

# BINARY SEARCH — halves the range each time
minNumber = 0
maxNumber = 100
currentNumber = round((maxNumber + minNumber) / 2)
foundNumber = False
while not foundNumber:
    if currentNumber == hiddenNumber:
        print("Found:", currentNumber, "(binary search)")
        foundNumber = True
    elif hiddenNumber > currentNumber:
        minNumber = currentNumber
    else:
        maxNumber = currentNumber
    currentNumber = round((maxNumber + minNumber) / 2)
# This took only 7 comparisons
📺 Both find 19 — linear search uses 19 comparisons; binary search uses only 7
  • Linear search: start at item 1, check it. If it matches — done. If not — move to item 2 and check again
  • Binary search: (1) find the midpoint of the current range, (2) if it matches — done
  • Efficiency comparison for finding number 19 in a list of 1 to 100: linear search needed 19 checks; binary search needed
✅ Knowledge Check
Q1 Describe how a linear search works in your own words.
It checks each item one by one from the start of the list until it finds the target item, or reaches the end of the list without finding it.
Q2 Describe how a binary search works in your own words.
It finds the middle item — if it matches, done. If the target is higher, it searches only the upper half. If lower, it searches only the lower half. It keeps halving the search range until found.
Q3 Binary search finds number 19 in a sorted list of 1 to 100.
7 — binary search roughly halves the remaining range each time, so it takes approximately log2(100) which is about 7 comparisons.
