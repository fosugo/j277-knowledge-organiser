Introduction to Spreadsheets
📚 Key Vocabulary
Cell Reference
The unique address of a cell — column letter then row number. For example, A1 is the very first cell (top-left). B5 means column B, row 5.
Formula
A calculation that always starts with =. Uses cell references or numbers. For example, =B2+B3 adds the values in B2 and B3 together.
Function
A built-in shortcut for a common calculation. For example, =SUM(E2:E12) adds every value from E2 down to E12. =AVERAGE(B2:B12) finds the mean.
Relative Cell Reference
A reference that automatically adjusts when you copy a formula to another cell. =B2*D2 in row 2 becomes =B3*D3 when copied to row 3.
Range
A group of cells written as Start:End. For example, B2:B12 means all cells from B2 down to B12.
💡 Big Ideas
  • Spreadsheets organise data into rows (numbered 1, 2, 3...) and columns (labelled A, B, C...). Every cell has a unique reference — column letter first, then row number, e.g. C4 means column C, row 4.
  • All formulas must start with = . Use + to add, - to subtract, * to multiply, and / to divide. Example: =C2*2 multiplies whatever is in cell C2 by the number 2.
  • =SUM(E2:E12) adds up all 11 values between E2 and E12. =AVERAGE(B2:B12) calculates the mean of all values between B2 and B12.
  • When you copy a formula down a column, relative references update automatically. =B2*D2 in row 2 becomes =B3*D3 in row 3 — saving you from rewriting every formula.
  • Keyboard shortcut: press Ctrl+` (the key to the left of 1) to toggle between showing formulas and showing the calculated results in a spreadsheet.
✅ Knowledge Check
Q1 A spreadsheet cell is in column C and row 5. What is its cell reference?
C5 — the column letter always comes first (C), then the row number (5).
Q2 Every spreadsheet formula must start with which symbol?
= (equals sign) — this tells the spreadsheet that what follows is a calculation, not just text.
Q3 What does =SUM(B2:B10) calculate?
It adds together all the values in cells B2 through to B10 — that is 9 cells added in one formula.
Q4 You write =B2*D2 in row 2 and copy it to row 3. What does the formula become in row 3?
=B3*D3 — relative cell references automatically update the row number when the formula is copied down.
Q5 What keyboard shortcut switches a spreadsheet between showing formulas and showing values?
Ctrl+` (hold Ctrl and press the backtick key, which is to the left of the number 1).

L2
Computer Models & Cell Referencing
📚 Key Vocabulary
Computer Model
A program that uses equations to simulate or predict real-world behaviour. Examples: weather forecasts, flight simulators, financial planning spreadsheets.
Absolute Cell Reference
A reference that stays fixed when a formula is copied — written with dollar signs. =$B$4 always points to cell B4 no matter where the formula is moved.
Relative Cell Reference
A reference that changes when a formula is copied. =B4 becomes =B5 when copied down one row.
Cell Formatting
Changing how a cell looks — font size, bold, fill colour, borders, or merging cells together — to make the spreadsheet clearer and more professional.
Merge Cells
Joining two or more cells into one larger cell. Commonly used for titles and headings that need to span several columns.
💡 Big Ideas
  • Computer models simulate the real world using equations. Examples: weather forecasting, flight simulator training, testing bridge stress, and business financial planning.
  • Models are useful but never perfect — they may not include every real-world factor. A speed model that ignores air resistance will predict impossible speeds after a few seconds.
  • Use an absolute reference ($B$4) when you want a cell to always point to the same place even when you copy the formula. Add $ before the column letter AND before the row number.
  • Quick rule: relative reference =B4 changes when copied; absolute reference =$B$4 always stays fixed. Use absolute when many formulas need to share one shared value (like a tax rate).
  • Formatting makes spreadsheets easier to understand: change font size and colour, add fill colours, draw borders around cells, and use merge cells to create clear headings.
✅ Knowledge Check
Q1 What is a computer model?
A program that uses algorithms and equations to simulate or predict the behaviour of a real-world system.
Q2 Give TWO real-world examples of where computer models are used.
Any two of: weather forecasting, flight simulators, bridge/building stress testing, testing car aerodynamics, financial planning.
Q3 You copy =B4*C4 from row 4 down to row 5. What does the formula become in row 5?
=B5*C5 — relative references automatically update the row number when copied down.
Q4 Every formula in your spreadsheet needs to multiply by the VAT rate stored in cell B1. Which reference should you use for B1?
=$B$1 — both $ signs fix the reference so it always points to B1 no matter where the formula is copied.
Q5 What does 'merge cells' do?
It joins two or more cells together to make one larger cell — often used to create a title heading that spans several columns.

L3
Creating a Financial Model
📚 Key Vocabulary
Financial Model
A spreadsheet that predicts income, costs and profit for a business — used to test scenarios safely without any real-world risk.
Profit
Money left over after all costs are paid. Formula: Profit = (Selling Price - Cost Price) x Quantity Sold.
Cost Price
The amount it costs the business to make or buy the product.
Selling Price
The amount the customer pays to buy the product.
Proportion
A fraction used to scale one value from another. If UK viewers = 5 million and USA viewers = 10 million, UK sales are predicted as 5/10 = 0.5 of USA sales.
💡 Big Ideas
  • A financial model spreadsheet lets a business predict profit before spending any real money — change the selling price and instantly see how profit changes.
  • Profit formula in a spreadsheet: =(C11-B11)*E11 where C11 = selling price, B11 = cost price, E11 = quantity sold. The brackets ensure the subtraction happens before the multiplication.
  • To predict UK sales from USA data: proportion = UK viewers divided by USA viewers (e.g. 5 million divided by 10 million = 0.5). UK sales = USA sales multiplied by 0.5.
  • Store the proportion in one cell (e.g. B8) and use an absolute reference =$B$8 in every sales formula — so if the proportion changes, all predicted sales update at once.
  • Changing the selling price in the model instantly recalculates all profits — letting you test 'what if I charge £2 more?' with no real risk.
✅ Knowledge Check
Q1 What is profit?
The money left after costs are paid. Profit = (Selling Price - Cost Price) x Quantity Sold.
Q2 A mug costs £3.50 to make and sells for £8.00. You sell 200 mugs. What is the profit?
(£8.00 - £3.50) x 200 = £4.50 x 200 = £900 profit.
Q3 The USA had 10 million viewers and the UK has 5 million. What proportion of USA sales would you use to predict UK sales?
0.5 (half) — 5 million divided by 10 million = 0.5, so UK sales are predicted as 50% of USA sales.
Q4 Why use =$B$8 instead of =B8 when copying a proportion formula down a column?
=$B$8 is an absolute reference that stays fixed when copied. =B8 would change to =B9, =B10 etc., pointing to the wrong cells.
Q5 The profit formula in row 11 is =(C11-B11)*E11. What does it become when copied to row 12?
=(C12-B12)*E12 — relative references update the row number automatically when the formula is copied down.

L4
What-If Scenarios
📚 Key Vocabulary
What-If Analysis
Testing different values in a spreadsheet to see how changing one thing (such as the selling price) affects the outcome (such as profit).
Goal Seek
A built-in spreadsheet tool that automatically adjusts one cell's value until another cell reaches your target. For example: find the exact price that gives £3,000,000 profit.
MAX Function
Returns the largest value in a range. For example, =MAX(D11:D26) finds the highest value in cells D11 to D26.
IF Function
Returns one value if a condition is true, and a different value if false. Syntax: =IF(condition, value if true, value if false).
Conditional Formatting
Automatically changes a cell's colour or style based on its value — for example, cells with the highest sales turn green and the lowest turn red.
💡 Big Ideas
  • What-if analysis: change a value (e.g. selling price) and immediately see the effect on another value (e.g. profit). Great for exploring options without any real-world risk.
  • Goal Seek: you set the target (e.g. total profit = £3,000,000), choose which cell to adjust (e.g. T-shirt selling price), and the spreadsheet finds the exact value automatically.
  • =MAX(D11:D26) returns the single largest number in that range. =MIN(D11:D26) returns the smallest. Both are useful for spotting best and worst performers quickly.
  • =IF(F25=$F$28,"Best seller","") — if the profit in F25 equals the maximum profit stored in F28, it displays the text Best seller. Otherwise it displays nothing (empty string "").
  • Conditional formatting: set rules so cells automatically change colour based on their value. For example, green for the highest values and red for the lowest — making trends instantly visible.
✅ Knowledge Check
Q1 What does Goal Seek do?
It automatically adjusts the value of one cell until a target value is reached in another cell. For example: find the selling price that gives exactly £3,000,000 profit.
Q2 What does =MAX(D5:D20) return?
The single largest (maximum) value found anywhere in cells D5 through to D20.
Q3 =IF(B5>100,"High","Low") — what does it display when B5 contains the number 150?
High — because 150 is greater than 100, the condition is true, so the first option (High) is shown.
Q4 Conditional formatting changes a cell's colour based on its value — True or False?
True — conditional formatting automatically applies colours or styles when a cell meets a rule you have set.
Q5 You want to find the exact selling price that gives a total profit of £5,000,000. Which tool would you use?
Goal Seek — it automatically adjusts a cell's value to make another cell reach a specific target.

L5
Validation & COUNTIF
📚 Key Vocabulary
Validation
Checking that data entered into a cell is sensible before accepting it. For example, a drop-down list that only allows A (Adult), S (Student) or C (Child) to be entered.
List Validation
A type of validation that shows the user a drop-down menu — they can only choose from the values you specify, preventing typing errors.
COUNTIF Function
Counts cells in a range that match a specific value. Syntax: =COUNTIF(range, criteria). Example: =COUNTIF(E9:P10,"A") counts all cells in E9:P10 containing the letter A.
Conditional Formatting Rule
A rule that automatically changes a cell's appearance when it meets a condition — for example, fill the cell grey as soon as any value is entered.
Empty String
Two speech marks with nothing between them: "". Used in IF formulas to display nothing at all when a condition is false.
💡 Big Ideas
  • List validation restricts a cell to only accept values from a list you create — shown as a drop-down. For a seat booking system: only A (Adult), S (Student) or C (Child) can be entered.
  • Conditional formatting can trigger when a cell is NOT empty — fill it grey to show it is booked. This means any entry (A, S or C) instantly colours the seat without needing a separate formula.
  • =COUNTIF(E9:P10,"A") counts every cell in the range E9 to P10 that contains the letter A — giving the exact number of adult tickets sold in that section of the theatre.
  • Seat income formula: multiply the number of seats sold by the ticket price. For example: =COUNTIF(E9:P10,"A")*U13 calculates Adult Premium income (count of A seats multiplied by adult premium price in U13).
  • Combining validation (only valid entries allowed) with conditional formatting (instant visual feedback) creates a clear, error-proof seating system.
✅ Knowledge Check
Q1 What does validation do in a spreadsheet?
It checks that data entered is sensible — for example, a drop-down list that only allows certain values prevents users from making typing mistakes.
Q2 What does =COUNTIF(B2:B20,"S") count?
It counts the number of cells in the range B2 to B20 that contain the letter S.
Q3 A conditional formatting rule fills a seat cell grey when it is NOT empty. You type S into a seat cell. What happens?
The cell instantly turns grey — showing that the seat has been booked.
Q4 Which type of validation shows the user a drop-down list of allowed values?
List validation — it restricts the cell to only accept values from a predefined list shown as a drop-down menu.
Q5 You want to count all Adult (A) premium seats sold in the range E9 to P10. Write the correct COUNTIF formula.
=COUNTIF(E9:P10,"A") — this counts every cell in that range that contains the letter A.

Macros & Charts
📚 Key Vocabulary
Macro
A small recorded program that automates a repetitive task in a spreadsheet. Record your actions once, then replay them instantly by clicking a button.
Developer Tab
A hidden tab in Excel that must be enabled before you can create macros. Enable it via: File, Options, Customize Ribbon, tick Developer.
Bar Chart
A chart using rectangular bars to compare values across different categories. Best for showing differences or changes over time.
Pie Chart
A circular chart divided into slices. Shows what proportion or percentage each category makes up of the total. Becomes hard to read with many slices.
Assign Macro
Linking a recorded macro to a button shape so that clicking the button runs the macro automatically.
💡 Big Ideas
  • Macros automate repetitive tasks. To clear all booked seats after a concert: record the deletion steps as a macro, assign it to a button, then clear everything with one click.
  • Recording a macro: Developer tab, Record Macro, carry out your actions, then click Stop Recording. To run it from a button: draw a shape, right-click, Assign Macro, choose your macro name.
  • Bar charts are best for comparing values across categories or showing changes over time. Example: how many seats remain for Premium, Standard and Economy — easy to compare at a glance.
  • Pie charts are best for showing proportions of a whole. However, they become difficult to read with many segments. If one ticket type has one seat left, the pie still looks like a complete circle — very misleading.
  • Always choose the chart type that makes the data clearest for the person reading it. If you want to show how many of each ticket type remain, a bar chart is much clearer than a pie chart.
✅ Knowledge Check
Q1 What is a macro?
A small recorded program that automates a repetitive task — you record your actions once and then replay them with a single button click.
Q2 Which Excel tab must be enabled before you can create macros?
Developer — it is hidden by default and must be enabled via File, Options, Customize Ribbon.
Q3 You want to compare the number of remaining seats for Premium, Standard and Economy ticket types. Which chart type is clearer?
Bar chart — it makes it easy to compare the exact number of remaining seats for each ticket type at a glance.
Q4 A pie chart shows one remaining seat for each of three ticket types. Why is this misleading?
The pie still appears as a complete, equal circle — it does not show how few seats are left, only that each type has the same proportion of remaining seats.
Q5 How do you link a macro to a button so users can run it with one click?
Draw a shape to use as the button, right-click it, select Assign Macro, then choose the name of the macro you recorded.

Describe step-by-step how you would: (1) record a macro to clear all seat bookings, (2) assign it to a clearly labelled button, and (3) create a bar chart showing the number of remaining seats for each ticket type. Explain why a bar chart is better than a pie chart here.

The Internet
📚 Key Vocabulary
Internet
A worldwide collection of interconnected computer networks. The Internet is the physical infrastructure — cables, routers and servers that connect devices across the globe.
World Wide Web (WWW)
One service that runs ON the Internet — it delivers web pages to your browser using HTTP. Other services that also use the Internet include email, VoIP calls and file transfer.
URL (Uniform Resource Locator)
The complete address of a resource on the Internet. Example: https://www.bbc.co.uk/news/index.html
Protocol
A set of agreed rules for communication. HTTP (Hypertext Transfer Protocol) defines exactly how web pages are sent and received between computers.
DNS Server
Domain Name System server — translates a human-readable domain name such as www.google.co.uk into the numerical IP address 142.250.187.195 that computers actually use.
💡 Big Ideas
  • The Internet is the global physical network of connected computers (the roads). The World Wide Web is just ONE service that uses it (like delivery vans that use the roads). Email, VoIP and file transfer are other services.
  • A URL has several distinct parts: protocol (https://) + subdomain (www.) + domain name (bbc.co.uk) + directory path (/news/) + filename (index.html). Each part has a specific role.
  • Domain extensions identify the type or location of a site: .gov.uk = UK government, .sch.uk = UK school, .ac.uk = UK university/college, .co.uk = UK company, .com = commercial, .org = organisation.
  • When you type a web address, your computer asks a DNS server to translate the name into an IP address — like looking up a number in a phone directory. Without DNS you would have to memorise numbers like 142.250.187.195.
  • Data is split into small chunks called packets before being sent. Each packet may take a different route across the Internet and arrive at different times — they are reassembled in the correct order at the destination.
✅ Knowledge Check
Q1 What is the key difference between the Internet and the World Wide Web?
The Internet is the global physical network (cables, routers, servers). The World Wide Web is one service that uses the Internet to deliver web pages — email and VoIP also use the Internet but are not the Web.
Q2 What does a DNS server do?
It translates a human-readable domain name (such as www.google.co.uk) into a numerical IP address (such as 142.250.187.195) that computers can use to find the correct server.
Q3 Which domain extension is used for UK school websites?
.sch.uk — this extension is specifically used for UK school websites.
Q4 What is a protocol? Give one example.
A set of agreed rules for communication. Example: HTTP (Hypertext Transfer Protocol) defines how web pages are sent and received.
Q5 Why is data split into packets before being sent over the Internet?
Packets can travel by different routes, making transmission more flexible and reliable. If one route is busy or broken, packets take another route. They are reassembled at the destination.

Connectivity & Bandwidth
📚 Key Vocabulary
Bandwidth
The maximum amount of data that can travel through a connection per second. Measured in bits per second — for example, 100 Mb/s (megabits per second).
Twisted Pair Copper Cable
The most common network cable — pairs of copper wires twisted together to reduce electrical interference. Used in most homes and offices.
Fibre Optic Cable
A cable that carries data as pulses of light through very thin glass or plastic fibres. Much faster than copper cable — used for broadband and submarine cables.
Coaxial Cable
A cable with a central copper core surrounded by insulation and a metal shield. Used for TV aerials and older network installations.
Buffering
Pre-loading the next few seconds of a video or audio stream into temporary storage so playback can continue smoothly even if the connection briefly slows down.
💡 Big Ideas
  • Bandwidth is like the width of a pipe — a wider pipe carries more water per second. Higher bandwidth = more data per second. Modern home broadband is typically 100 Mb/s — over 1,750 times faster than year-2000 modems (56 kb/s).
  • Calculating download time: Step 1 — convert Mb/s to MB/s by dividing by 8 (there are 8 bits in 1 byte). Step 2 — divide file size (MB) by the speed (MB/s). Example: 300 MB file at 100 Mb/s: 100 divided by 8 = 12.5 MB/s, then 300 divided by 12.5 = 24 seconds.
  • Units reminder: 8 bits = 1 byte. 1,000 bytes = 1 kilobyte (kB). 1,000,000 bytes = 1 megabyte (MB). 1,000,000,000 bytes = 1 gigabyte (GB). Bandwidth uses bits (Mb/s); file sizes use bytes (MB).
  • Wireless connections send data through the air as radio waves. Advantages: no cables needed, devices can move around. Disadvantages: typically slower than cables, weaker signal through walls, less secure.
  • Buffering stores the next few seconds of a video locally. If the connection is too slow, the buffer empties faster than it fills — causing playback to pause and wait for more data to arrive.
✅ Knowledge Check
Q1 What is bandwidth?
The maximum amount of data that can be transferred through a connection per second — measured in bits per second (for example Mb/s or Gb/s).
Q2 A home connection has a bandwidth of 80 Mb/s. How long will it take to download a 400 MB file? Show your working.
Step 1: 80 Mb/s divided by 8 = 10 MB/s. Step 2: 400 MB divided by 10 MB/s = 40 seconds.
Q3 Which type of cable carries data as pulses of light and is much faster than copper?
Fibre optic cable — it transmits data as pulses of light through glass or plastic fibres, making it significantly faster than copper cables.
Q4 Give ONE advantage and ONE disadvantage of wireless connections compared to wired cables.
Advantage: no cables needed, allows devices to move freely. Disadvantage: typically slower than cables and less secure (the signal can be intercepted).
Q5 Why does video streaming use buffering?
Buffering stores the next few seconds of video locally so playback continues smoothly even if the Internet connection briefly slows down or drops out.

L3
Network Topologies
📚 Key Vocabulary
LAN (Local Area Network)
A network of computers connected within a small geographical area — for example, a school, a single office building, or a home.
WAN (Wide Area Network)
A network that connects two or more LANs across a large geographical area. The connections use dedicated telecommunications cables called leased lines. The Internet is the world's largest WAN.
Network Topology
The way devices in a network are connected and arranged. Common topologies include bus and star.
Bus Network
All devices connect to one single shared cable (the bus). A terminator at each end of the cable stops the signal from bouncing back.
Star Network
Each device has its own individual cable connecting it directly to a central switch or hub. If one cable fails, only that one device is affected.
💡 Big Ideas
  • LAN = one building or site (school, office, home). WAN = joins LANs across large distances using leased lines. The Internet is the world's largest WAN connecting millions of LANs globally.
  • Bus network: all computers share ONE cable. Cheap and easy to install. However, if the cable is cut or damaged, ALL computers on the network lose their connection instantly.
  • Star network: each computer has its own cable to a central switch. If one cable fails, only that computer is affected — all others continue working. More reliable, but more expensive (more cable, plus a switch needed).
  • Network hardware: a SWITCH connects devices in a star network and sends data only to the intended recipient (faster). A ROUTER connects a LAN to the Internet and directs packets towards their destination.
  • A Network Interface Card (NIC) is the hardware inside every device that connects it to a network. Modern laptops and phones have wireless NICs built in. Desktop computers often use a wired NIC.
✅ Knowledge Check
Q1 What is the difference between a LAN and a WAN?
A LAN connects devices in a small area (one building or site). A WAN connects two or more LANs across large distances, using leased lines — the Internet is the world's largest WAN.
Q2 In a bus network, what happens if the main cable is cut?
All computers on the network immediately lose their connection — because every device shares that single cable.
Q3 Which topology gives each device its own cable connected to a central switch?
Star network — each device has its own dedicated cable to the central switch, so a single cable failure only disconnects one device.
Q4 What is the job of a router on a network?
A router examines data packets and routes (directs) them towards their destination. It also connects a LAN to the Internet.
Q5 Give ONE advantage and ONE disadvantage of a star network compared to a bus network.
Advantage: more reliable — one cable failure only affects one device. Disadvantage: more expensive — each device needs its own cable and a switch is required.

L4
Network Types
📚 Key Vocabulary
Client-Server Model
A network architecture where a powerful server provides services, and client computers make requests to receive those services. Examples: web servers, file servers, database servers.
Server
A powerful, dedicated computer that provides a service — a web server delivers web pages, a file server stores shared files, a print server manages printers.
Peer-to-Peer Network (P2P)
A network where all devices are equal — each one can share its own resources (printer, storage) directly with others. No dedicated server is needed.
Cloud Computing
Using software, storage and processing power that is hosted on remote servers accessed via the Internet — rather than on your own computer. Examples: Google Drive, OneDrive, Office 365.
Data Centre
A large facility housing thousands of servers. Cloud computing services are typically run from data centres located around the world.
💡 Big Ideas
  • Client-server model: the client (your browser) sends a request, the server processes it and sends back the response (the web page). Used for web servers, file servers and database servers.
  • Client-server advantages: centralised management, data is easily backed up, good security control. Disadvantages: expensive dedicated server hardware needed, single point of failure (server down = all clients affected).
  • Peer-to-peer networks: each computer shares its own resources directly. Advantages: cheap (no dedicated server), simple to set up. Disadvantages: harder to manage, slower as more devices join, less secure.
  • Cloud computing gives access to software and storage over the Internet. Advantages: access from any device anywhere in the world, automatic backups, no expensive hardware needed locally. Disadvantage: requires a reliable Internet connection.
  • Cloud examples: Google Drive (storage), Office 365 (software), school management systems. All process and store data on remote servers, not your local computer.
✅ Knowledge Check
Q1 Describe the client-server model.
Client computers (such as your browser) send requests to a powerful server. The server processes the request and sends back a response — such as a web page, file or database query result.
Q2 Give ONE advantage and ONE disadvantage of a client-server network.

Q3 In a peer-to-peer network, which device acts as the server?
All devices can act as both client and server — every device can share its own resources and use the resources of others.
Q4 Give ONE real-world example of a cloud computing service.
Any of: Google Drive, OneDrive, Office 365, Google Docs, a school management system accessed online.

Encryption
📚 Key Vocabulary
Encryption
Converting data into a coded, unreadable form (cipher text) so that anyone who intercepts it cannot understand it without the correct key.
Plaintext
The original, readable data before it is encrypted. Example: the word HELLO.
Cipher Text
The scrambled, unreadable result after encryption. Example: KHOOR is HELLO encrypted with a Caesar cipher using key 3.
Encryption Key
The value used to encrypt and decrypt data. In a Caesar cipher, the key is the number of positions each letter is shifted along the alphabet.
Caesar Cipher
A simple substitution cipher where each letter is replaced by a letter a fixed number of places further along the alphabet. Key 3 means A becomes D, B becomes E, and so on.
💡 Big Ideas
  • Encryption scrambles data so only someone with the correct key can read it. The padlock symbol in your browser means HTTPS is being used — your data is encrypted as it travels to the website.
  • Caesar cipher with key 3: A becomes D, B becomes E, C becomes F, and so on. To encrypt HELLO: H becomes K, E becomes H, L becomes O, L becomes O, O becomes R — giving KHOOR. To decrypt, shift back by 3.
  • A TLS/SSL certificate (shown when you click the padlock) proves the website is who it claims to be — like an official ID card. It is issued by a trusted third party called a Certificate Authority.
  • Brute-force attack on a Caesar cipher: try every possible shift (only 25 options). A computer can crack all 25 in a fraction of a second. Modern encryption is far more complex — using mathematical problems that would take billions of years to solve.
  • Modern encryption (like that used by banks and online shops) uses mathematical problems that are easy to calculate one way but practically impossible to reverse without the key.
✅ Knowledge Check
Q1 What is encryption?
Converting data into a coded, unreadable form (cipher text) so that anyone who intercepts it cannot understand it without the correct decryption key.
Q2 Using a Caesar cipher with a key of 3, what does the letter H encrypt to?
K — shift H forward 3 places in the alphabet: H to I to J to K.
Q3 Encrypt the word CAT using a Caesar cipher with a key of 3.
FDW — C shifts to F, A shifts to D, T shifts to W (each letter moved 3 places forward in the alphabet).
Q4 What does the padlock symbol next to a web address tell you?
The connection is using HTTPS — the data is encrypted in transit so anyone intercepting it cannot read it.
Q5 Why is a Caesar cipher not safe enough to protect sensitive data today?
There are only 25 possible keys — a computer can try all 25 in a fraction of a second. Modern encryption uses vastly more complex mathematical problems that would take billions of years to crack.

📚 Key Vocabulary

A UK law making it illegal to: access a computer without permission, access files without authorisation, prevent or hinder access to programs or data, or damage programs or data.

A type of malware that can replicate itself and spread to other files and computers — like a biological virus that passes from person to person.
Ransomware
Malware that encrypts all files on a computer and demands a payment (ransom) for the decryption key to restore access.
💡 Big Ideas
  • The Computer Misuse Act (1990) makes four things illegal: gaining unauthorised access to a computer system, gaining unauthorised access to files, preventing access to programs or data, and damaging or impairing programs or data.
  • Hackers' motivations vary: the personal challenge, financial gain (ransomware or stolen data), stealing commercial or government secrets, political activism, or embarrassing people or organisations.

L3
Passwords & Email Scams
📚 Key Vocabulary
Brute-Force Attack
Trying every possible combination of characters until the correct password is found. A simple 3-digit numeric password has only 1,000 combinations — a computer can try all of them instantly.
Dictionary Attack
Trying every word in a dictionary (around 60,000 words) as the password. Any single common word — even with obvious substitutions like 3 for e — can be cracked very quickly.
Phishing
A scam email designed to look genuine (e.g. from a bank or PayPal) that tricks you into clicking a link and entering personal details on a fake website.
Trojan Horse
Malware disguised as a legitimate, harmless program (e.g. a free game or email attachment) that secretly installs harmful code when you open it.
Advance Fee Fraud
A scam that promises a large sum of money but asks you to pay a small fee first — the promised money never arrives.
💡 Big Ideas
  • Strong password rules: use 14 or more characters, mix uppercase and lowercase letters, include numbers and special characters such as #$£^&, avoid any personal information, and use random unrelated words.
  • Memorable strong password technique: combine three unrelated words with numbers and symbols between them. Example: sunset#GIRAFFE7music — easy to remember but practically impossible to guess.
  • Spotting phishing emails: generic greeting (Dear Customer instead of your actual name), spelling or grammar mistakes, urgent threatening language, links that show a suspicious domain when you hover over them.
  • Trojan horses are disguised as genuine files — a spreadsheet, document or free software download. When you open them, they silently install malware. Never open unexpected email attachments.
  • Malware-generated spam: some viruses read your contacts list and automatically send infected emails to everyone in your address book — spreading the virus further without your knowledge.
✅ Knowledge Check
Q1 List THREE features that make a password strong.
Any three of: 14+ characters, mix of uppercase and lowercase, includes numbers, includes special characters (#$£^), no personal information, uses random unrelated words.
Q2 How does a dictionary attack attempt to crack a password?
It systematically tries every word in a dictionary as the password. Any password that is a single common word (even with simple substitutions) can be cracked very quickly this way.
Q3 You receive an email from 'PayPal' asking you to click a link and confirm your bank details. Give TWO signs it could be a phishing email.
Any two of: generic greeting (Dear Customer), spelling mistakes, suspicious link domain (not paypal.com), urgent threatening tone, requests for bank details.
Q4 What is a Trojan horse?
Malware disguised as a legitimate, useful program that secretly installs harmful code when opened — for example, a free game or email attachment.
Q5 Approximately what percentage of all email was spam in 2022?
49% — by 2022 approximately half of all global email traffic was spam (reduced from about 80% in 2011).

Copyright
📚 Key Vocabulary
Copyright
The legal right protecting the creator of an original work from having it copied without permission. Indicated by the symbol ©.
Copyright Infringement
Breaking copyright law — for example, downloading a film illegally, sharing a copyrighted song without permission, or using a copyrighted image in a public document without a licence.
Plagiarism
Copying someone else's work (writing, music, images, video) and presenting it as your own — even if you do not make any money from it.

Health & Safety
📚 Key Vocabulary
RSI (Repetitive Strain Injury)
Pain or damage caused by repeatedly making the same movements over a long period — for example, typing or using a mouse for many hours without adequate breaks.
Ergonomics
Designing workstations, tools and equipment to fit the human body comfortably and safely — reducing the risk of injury during prolonged computer use.
CO2 Fire Extinguisher
The correct fire extinguisher for electrical fires (such as a computer fire). Water extinguishers must never be used on electrical fires as water conducts electricity.
Blue Light
High-energy light emitted by LED screens. Exposure to blue light before bedtime suppresses melatonin production and makes it harder to fall asleep.
Trip Hazard
Anything that could cause someone to trip and fall — including loose cables, bags on the floor, chairs not pushed in, or poorly placed furniture.
💡 Big Ideas
  • Common health problems from prolonged computer use: eye strain and headaches (from screen glare and blue light), RSI in wrists and hands (from repetitive mouse and keyboard use), and back pain from poor posture.
  • Correct workstation setup: screen at arm's length (approximately 45 cm) at or slightly below eye level, back fully supported, elbows at 90-120 degrees, feet flat on the floor, wrist support for the mouse hand.
  • Health and safety regulations require computer workstations to have: a screen that does not flicker, the ability to tilt and swivel, no distracting glare or reflections, a keyboard that can be repositioned, and a height-adjustable chair.
  • Employers have legal duties: to ensure the health and safety of all employees, to make the workplace safe for visitors and non-employees, and to carry out regular risk assessments.
  • Fire safety in computer rooms: CO2 extinguishers are safe for electrical fires. Water extinguishers would conduct electricity and could seriously injure or kill the person using them — never use water on a computer fire.

Strings, Variables & Input
📚 Key Vocabulary
Variable
A named location in memory that stores a value. Think of it as a labelled box — you choose the name, and Python stores the value inside. Example: age = 14 stores the number 14.
String
A piece of text in Python. Strings must always be wrapped in speech marks. Example: name = "Aisha" stores the text Aisha in a variable called name.
print()
Displays output on the screen. Example: print("Hello!") shows the word Hello! on screen. You can also print the value of a variable: print(name)
input()
Waits for the user to type something and press Enter, then stores what they typed. Example: colour = input("What is your favourite colour? ") stores the user's answer in a variable called colour.
Syntax Error
A mistake that breaks the rules of the Python language — like a grammar error in English. Python cannot run the program at all and shows a red error message. Example: Print("Hello") fails because P must be lowercase.
💡 Big Ideas
🐍 A simple personalised greeting

print("Welcome to the program!")
📺 Asks the user for their name, then displays: Hello, [whatever name they typed] Welcome to the program!
  • Every program that asks the user a question uses this pattern: print() to ask the question, then input() to capture the answer. Example: print("What is your name?") then firstname = input()
  • Variable naming rules: only letters, numbers and underscores; cannot start with a number; cannot use Python keywords like print or input; always choose meaningful names. firstName is better than x.
  • Syntax errors happen when Python cannot understand what you wrote — common causes: wrong spelling (primt instead of print), wrong capitalisation (Print instead of print), missing speech marks around text.
  • Comments start with # and are completely ignored when the program runs. Use them to explain what each section of your code does. Example: # This program asks for the user's name
  • When Python shows an error message, it tells you the line number and explains what went wrong. Always read it carefully — it tells you exactly where to look and gives a clue about the fix.

Q2 What does the input() function do?
It waits for the user to type something and press Enter, then stores whatever they typed so it can be used later in the program.

Data Types & Arithmetic
📚 Key Vocabulary
Integer (int)
A whole number with no decimal point. Examples: 14, 0, -3, 100. Use int() to convert a string to an integer. Example: age = int(input("Enter your age: "))
Float
A number with a decimal point. Examples: 3.14, 9.99, -0.5. Use float() to convert a string to a float. Example: price = float(input("Enter the price: "))
String (str)
Text data that must be in speech marks. Input from the user using input() is always stored as a string by default — even if the user types a number.
Casting
Converting a value from one data type to another. Example: int("25") converts the string "25" into the integer 25. str(42) converts the integer 42 into the string "42".
Concatenation
Joining two strings together using the + symbol. Example: "Hello " + "World" produces Hello World. Numbers must be converted to strings first using str() before they can be joined.
💡 Big Ideas
🐍 Calculating the average of two prices
# Ask the user for two item prices
item1 = float(input("Enter the price of item 1: £"))
item2 = float(input("Enter the price of item 2: £"))
# Calculate the total and average
total = item1 + item2
average = round(total / 2, 2)
# Display the result
print("The average price is: £" + str(average))
📺 Asks for two prices, calculates the average rounded to 2 decimal places, and displays it with a £ sign
  • Python always stores user input as a string. If you want to do arithmetic with the value, you must convert it first. Example: number = int(input("Enter a number: ")) then print(number + 10) — this adds 10 to the number.
  • Arithmetic operators: + adds, - subtracts, * multiplies, / divides (gives a decimal), // integer divides (removes decimal part), % modulo finds the remainder, ** raises to a power.
  • Python follows BIDMAS — the same order of operations as in maths. Use brackets to control the order: (3 + 4) * 2 = 14, but 3 + 4 * 2 = 11 (multiplication happens before addition).
  • Concatenation joins strings: "My age is " + str(14) + " years" produces My age is 14 years. The number 14 must be converted to str(14) before it can be joined with the surrounding text.
  • The round() function rounds a decimal to a set number of decimal places. Example: round(3.14159, 2) gives 3.14 — useful when displaying prices or measurements.

Selection — If, Elif & Else
📚 Key Vocabulary
if statement
Runs a block of code ONLY when a condition is true. Syntax: if condition: followed by the indented code to run. The colon : means 'then' in Python.
else
Runs a block of code when the if condition is NOT true — the alternative path. Always paired with an if statement.
elif
Short for 'else if' — checks a further condition when the previous if or elif was not true. You can chain as many elif statements as needed.
Comparison Operators
Symbols used to compare values in a condition: == (equal to), != (not equal to), > (greater than), < (less than), >= (greater than or equal to), <= (less than or equal to).
Indentation
The 4 spaces at the start of a line that tell Python which code belongs inside an if, elif or else block. Wrong indentation either crashes the program or causes wrong results.
💡 Big Ideas
🐍 Speed radar checker using if/elif/else
# Speed radar program
speed = int(input("Enter the driver's speed in mph: "))
if speed >= 100:
    print("Ban from driving")
elif speed > 70:
    print("Issue fine")
else:
    print("No action required")
📺 Asks for a speed then decides: ban from driving (100+ mph), issue fine (71-99 mph), or no action (70 mph or under)
  • The if/elif/else structure: if condition: (4 spaces) indented code elif another_condition: (4 spaces) indented code else: (4 spaces) indented code. Python uses a colon : to mean 'then do this'.
  • == means 'is equal to' and is used in comparisons. = means 'assign a value to a variable'. Never confuse them: if age = 18 is wrong; if age == 18 is correct.
  • Indentation is not optional in Python — it is the language's way of showing which code belongs inside a block. 4 spaces is standard. Missing or inconsistent indentation causes errors.
  • elif checks conditions in order — Python stops as soon as one condition is true and runs that block only. This is more efficient than writing multiple separate if statements.
  • Real example: age = int(input("Enter age: ")) then if age >= 18: print("Adult") elif age >= 13: print("Teenager") else: print("Child")
✅ Knowledge Check
Q1 What is the difference between = and == in Python?
= assigns a value to a variable (e.g. age = 16 stores 16 in age). == compares two values in a condition (e.g. if age == 18: checks whether age equals 18). Using = in a condition is a very common mistake.
Q2 What does elif mean and when does it run?
elif means 'else if' — it checks a further condition when the previous if (or elif) condition was false. It only runs if all the conditions before it were false.
Q3 A program has: if grade >= 80: print("Distinction") elif grade >= 60: print("Pass") else: print("Fail"). What does it print when grade = 65?
Pass — 65 is not >= 80 (first condition is false), but 65 IS >= 60 (elif condition is true), so Pass is displayed.
Q4 Why is correct indentation important in Python?
Python uses indentation (4 spaces) to identify which lines of code belong inside an if, elif or else block. Wrong indentation causes either a crash or incorrect behaviour — Python has no braces like other languages.
Q5 Write the Python comparison operator that means 'not equal to'.

Algorithms & Error Types
📚 Key Vocabulary
Algorithm
A precise, step-by-step set of instructions for solving a specific problem or completing a task. Every computer program is an implementation of an algorithm.
Pseudocode
An informal, structured way of planning an algorithm using plain English mixed with programming-style commands. Cannot be run by a computer — used for planning before writing real code.
Syntax Error
A coding mistake that breaks the rules of the Python language. Python cannot understand the code and refuses to run the program at all. Red error message shown.
Run-Time Error
An error that occurs while the program is actually running. The code looked correct but something goes wrong during execution. Example: dividing by zero crashes the program with a ZeroDivisionError.
Logic Error
An error where the program runs without crashing but produces the wrong result. No error message is shown — only careful testing reveals the mistake.
💡 Big Ideas
🐍 Pseudocode plan translated into Python
# PSEUDOCODE PLAN:
# INPUT grade
# IF grade >= 80 THEN OUTPUT "Distinction"
# ELIF grade >= 60 THEN OUTPUT "Pass"
# ELSE OUTPUT "Fail"

# PYTHON CODE:
grade = int(input("Enter your grade (0 to 100): "))
if grade >= 80:
    print("Distinction")
elif grade >= 60:
    print("Pass")
else:
    print("Fail")
📺 Asks for a grade and outputs Distinction (80+), Pass (60-79) or Fail (below 60)
  • Pseudocode planning: use OUTPUT instead of print, INPUT instead of input, arrows (←) for assignment, and familiar maths symbols. Example: OUTPUT "Enter a number" then total ← number1 + number2
  • Syntax errors: misspelled function name (primt instead of print), missing closing bracket or speech marks, wrong capitalisation. Python cannot run the program and shows a red error message with a line number.
  • Run-time errors: dividing by zero (ZeroDivisionError), accessing memory that does not exist. The program starts, runs some code, then suddenly crashes. The error message tells you what went wrong.
  • Logic errors are the hardest to find — the program runs perfectly but gives the wrong answer. Example: using total = a - b when the program should add them. You must test thoroughly to catch these.
  • Debugging strategy: for syntax errors, read the error message and line number. For logic errors, add temporary print() statements to check what values are stored in variables at each step.
✅ Knowledge Check
Q1 What is pseudocode used for?
Planning an algorithm before writing real code — it uses plain English mixed with programming-style commands. It helps you think through the logic without worrying about exact syntax.
Q2 A program runs without crashing but gives the answer 50 instead of 150. What type of error is this?
Logic error — the program runs successfully but produces the wrong result because of a mistake in the logic (for example using - instead of + for total).
Q3 What causes a ZeroDivisionError in Python?
Attempting to divide a number by zero — for example: result = 10 / 0. This causes a run-time crash because dividing by zero is mathematically undefined.
Q4 Find the syntax error in this code: prnt("Hello World")
prnt is misspelled — it should be print. Python does not recognise prnt as a valid function name and will refuse to run the program.
Q5 State ONE key difference between a syntax error and a logic error.
A syntax error prevents the program from running at all (Python shows an error message). A logic error lets the program run but produces incorrect results (no error message is shown).

While Loops
📚 Key Vocabulary
While Loop
A loop that repeats a block of code over and over as long as a condition remains true. The moment the condition becomes false, the loop stops and the program continues.
Iteration
One single execution of the code inside a loop. Each time the loop runs through its code once, that counts as one iteration.
Incrementing
Adding 1 to a variable. Written as: attempts = attempts + 1. This is used to count how many times something has happened inside a loop.
Boolean
A data type that stores only True or False. Commonly used as a flag variable to control whether a loop should keep running.
import random
A line that loads Python's built-in random number module. After importing, you can use random.randint(1, 6) to generate a random whole number between 1 and 6 inclusive.
💡 Big Ideas
🐍 Password checker — maximum 3 attempts
# Allow the user a maximum of 3 attempts
attempts = 0
correctPassword = False
while attempts < 3 and not correctPassword:
    password = input("Enter your password: ")
    attempts = attempts + 1
    if password == "abc123":
        print("Access Granted - Welcome!")
        correctPassword = True
    else:
        print("Incorrect password. " + str(3 - attempts) + " attempt(s) remaining.")
if not correctPassword:
    print("Account locked after 3 failed attempts.")
📺 Grants access if the correct password is entered within 3 attempts; locks account if all 3 attempts fail
  • While loop syntax: while condition: followed by (4 spaces) the indented code to repeat. The loop keeps running as long as the condition is True. When it becomes False, execution continues after the loop.
  • Example — keep asking for a password until correct: while password != "correct123": then password = input("Wrong! Try again: ") then print("Access granted!"). The loop only exits when the right password is entered.
  • Counting iterations: set attempts = 0 before the loop starts, then inside the loop write attempts = attempts + 1 to add 1 every time the loop runs. After the loop, print("You took", attempts, "attempts.").
  • Boolean flag pattern: set found = False before the loop. Inside, when the target is found, write found = True. The while condition reads: while not found: — this is a clean, readable way to control a loop.
  • Generating random numbers: write import random at the top of your program, then use number = random.randint(1, 6) to get a random whole number between 1 and 6 every time it runs.

Searching Algorithms
📚 Key Vocabulary
Linear Search
A search algorithm that checks each item one at a time, starting from the first, until the target item is found or the entire list has been checked.
Binary Search
A search algorithm that repeatedly divides a sorted list in half — checking the middle item, then eliminating the half that cannot contain the target.
Algorithm Efficiency
How quickly an algorithm completes, especially for large datasets. A more efficient algorithm requires fewer operations — binary search is far more efficient than linear search for large lists.
Sorted List
A list arranged in a specific order (e.g. smallest to largest, A to Z). Binary search can ONLY work correctly on a sorted list.
Midpoint
The middle element of the current section of the list being searched. Binary search always checks the midpoint first.
💡 Big Ideas
🐍 Linear search vs Binary search — side by side
# LINEAR SEARCH — checks every item one by one
hiddenNumber = 19
currentNumber = 1
foundNumber = False
while not foundNumber and currentNumber <= 100:
    if currentNumber == hiddenNumber:
        print("Found:", currentNumber, "(linear search)")
        foundNumber = True
    else:
        currentNumber = currentNumber + 1
# This took 19 comparisons

# BINARY SEARCH — halves the range each time
minNumber = 0
maxNumber = 100
currentNumber = round((maxNumber + minNumber) / 2)
foundNumber = False
while not foundNumber:
    if currentNumber == hiddenNumber:
        print("Found:", currentNumber, "(binary search)")
        foundNumber = True
    elif hiddenNumber > currentNumber:
        minNumber = currentNumber
    else:
        maxNumber = currentNumber
    currentNumber = round((maxNumber + minNumber) / 2)
# This took only 7 comparisons
📺 Both find 19 — linear search uses 19 comparisons; binary search uses only 7
  • Linear search: start at item 1, check it. If it matches — done. If not — move to item 2 and check again. Continue until found or the whole list is checked. Works on any list, sorted or unsorted.
  • Binary search: (1) find the midpoint of the current range, (2) if it matches — done. (3) if the target is higher, search only the upper half. (4) if the target is lower, search only the lower half. Repeat. MUST have a sorted list.
  • Efficiency comparison for finding number 19 in a list of 1 to 100: linear search needed 19 checks; binary search needed only 7. For a list of 1,000,000 items, binary search needs at most 20 checks.
  • Binary search limitation: it ONLY works on a sorted list. If the list is unsorted, you must sort it first — which adds extra processing time. For small lists (under about 10 items), linear search is often just as fast.
  • Real-world uses of binary search: a spell-checker looking up words in a sorted dictionary, finding a contact in a sorted address book, database searches on indexed (sorted) fields.
✅ Knowledge Check
Q1 Describe how a linear search works in your own words.
It checks each item one by one from the start of the list until it finds the target item, or reaches the end of the list without finding it.
Q2 Describe how a binary search works in your own words.
It finds the middle item — if it matches, done. If the target is higher, it searches only the upper half. If lower, it searches only the lower half. It keeps halving the search range until found.
Q3 Binary search finds number 19 in a sorted list of 1 to 100. Approximately how many comparisons does it need?
7 — binary search roughly halves the remaining range each time, so it takes approximately log2(100) which is about 7 comparisons.
Q4 Binary search can work on an unsorted list — True or False?
False — binary search ONLY works correctly on a sorted list. On an unsorted list it may miss the target entirely.
Q5 Give ONE specific real-world application where a binary search would be used.
Any of: spell-checker looking up words in a sorted dictionary, finding a contact in a sorted address book, searching an indexed database field.
